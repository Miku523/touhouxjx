# 东方新纪行 ～ Chronicle of Gensokyo

一款以《东方 Project》世界观为背景的同人动作游戏。纯原生 JavaScript + Canvas2D 实现，**零依赖、零构建**，用浏览器打开 `index.html` 就能玩。

---

## 内容概览

## 故事

幻想乡的春天停在了第七十天。樱不落、雾不散、湖骤冻、山风停、花海不谢、月相乱——
不是季节忘了走，是有人把「结束」藏了起来。

红魔馆地下，被关了四百九十五年的芙兰朵露，想看看一场不会结束的祭典。
她的愿望顺着地脉渗进幻想乡，把每个妖怪心里那点「没能好好告别」的东西放大成灾。

灵梦一路结束异变，却开始怀疑：把一切收尾，是不是也是一种遗憾；
魔理沙一路把喜欢的东西借走、收藏，却发现自己从没真正送出过什么。

遗憾结局里，两位主角都没能推开那扇门；真结局里她们走了进去，带芙兰朵露赴了春天的祭典。三个月后的 EXTRA，是第二次——把「下次」变成「每年」的那一次。
两条线从开场到每一面的道中、Boss 前、Boss 后都有各自的对话，道中推进到 26% / 55% 还会各插入一段剧情。

## 结局

| 结局 | 条件 |
| --- | --- |
| END 01 不落之春（灵梦 · 遗憾） | E 任意方式通关；或 N/H/L 使用过续命后通关 |
| END 02 春之尽头（灵梦 · 真结局） | N/H/L 通关，且一次续命都没有用过 |
| END 03 借来的春天（魔理沙 · 遗憾） | E 任意方式通关；或 N/H/L 使用过续命后通关 |
| END 04 还给春天的东西（魔理沙 · 真结局） | N/H/L 通关，且一次续命都没有用过 |
| W1 迟到的祭典（灵梦） | 使用灵梦通关 EXTRA |
| W2 第一次送人的宝贝（魔理沙） | 使用魔理沙通关 EXTRA |

「续命」指游戏结束后选择「再战 Boss / 重新挑战本关」；暂停菜单里的「重新开始本关」不计入续命，但会从本关开头重来。
E 难度只有 5 面，因此 E 通关必定进入遗憾结局，也不会解锁 EXTRA。
EXTRA 只有在达成 END 02 / END 04 后才会解锁；已经解锁后，后续再打遗憾结局也不会把它锁回去。EXTRA 通关只看主角，不受续命影响。

### 设置与键位

标题画面和暂停菜单都能进「设置」，两处内容一致（暂停来源会多一行「重新开始本关」，
标题来源会多一行「重置进度」）：

| 选项 | 说明 |
| --- | --- |
| 残机 | 1–4 条，`←` `→` 调整，下一局 / 重开本关时生效 |
| 全部静音 | 关掉所有声音（音效 + 音乐） |
| 背景音乐 / 音效 | 分别开关音乐与音效 |
| 音乐音量 / 音效音量 | `←` `→` 以 10% 为步进调整，0–100% 循环 |
| 屏幕震动 | 受击 / 爆发的镜头抖动 |
| 帧率上限 | 无上限 → 60 → 120 → 30 循环 |
| 按键设置 | 进入键位页：选中一项后按下新键即完成改键，`Del` 恢复默认 |
| 重置进度 | 仅标题画面的设置页有：二次确认后清掉通关记录，EXTRA 回到封闭状态（设置与键位保留） |
| 返回 | `Esc` 逐级返回，光标会停在刚才那一行 |

改键规则：每个动作有「主键 + 副键」，只改主键；新键若已被别的动作占用则自动互换，
若新键原本是别的动作的副键则清掉那条副键，保证任何时候都不会有两个动作抢同一个键。

设置保存在 `localStorage` 的 `hks.settings.v1`，键位保存在 `hks.keybinds.v1`，
通关进度保存在 `hks.progress.v1`（EXTRA 是否解锁 + 最近一次达成真结局的自机；只有 END 02 / END 04 会写入或更新解锁）；
进 EXTRA 会强制换回最近达成真结局的那一位，刷新或重开浏览器都还在。

## 音乐回忆室

标题菜单里的「音乐回忆室 / MUSIC ROOM」是一间东方风格的试听室：左边是唱片目录，右边是唱机与解说。不用通关、不用进关卡，随时都能进来听。11 首曲子按故事顺序编号 01–11（标题 medley、1–6 面、EXTRA、失败、结局、EXTRA 结局）。

**没遇到过的曲子显示「？？？」**。只有真正在旅途中响过一次的旋律，才会在目录里露出曲名、时长和唱片标签；没听过的编号被薄雾罩着，右边只写「锁在旧留声机里」。选中它按 `Enter`（或用鼠标点一下）不会直接播放，而是先问一次：

> 第 06 号唱片被一层薄雾罩着。提前播放会揭晓曲名、人物与解说——要现在听吗？

选「播放」才会响，同时把曲名、人物、地点、原曲出处、解说与 BPM 一并揭晓；选「取消」就原样留着，下次再问。已经听过的曲子点一下直接播放，再按一次 `Enter` 抬针。

操作：`↑` `↓` 选曲、`←` `→` 换曲、`Enter` 播放 / 停止、`T` 试听 30 秒、`M` 静音、`Esc` 回标题。播放时唱片高光会转、频谱跳动，进度条与循环次数实时更新。

只想先尝一口、不打算把整首听完，就按 `T`（或点底栏「试听 30 秒」）：进度条上会多出一根细针，标出 30 秒收针的位置；底栏倒计时走到 0 会自动抬针并显示「试听结束」，中途再按一次 `T` 可以提前收针。试听同样会揭晓未遭遇的曲目（确认框里的按钮会变成「试听 30 秒」）。

「听过」的判定挂在 `AudioEngine` 的 `onSongStart` 上：标题曲（进标题就响）、关卡 BGM、失败 / 结局曲只要真正响过一次就记下，**不需要打赢**；设置里把音乐关掉时切歌不算数，等重新打开音乐真正开播才记。记录写在 `localStorage` 的 `hks.music.v1`，和通关进度分开——重置进度只清 EXTRA 解锁，已经点亮的唱片留在音乐室里。
老存档（这个功能上线前就在玩）第一次打开时会按 `hks.progress.v1` 里的 EXTRA 解锁状态，把标题曲与 1–6 面补记为听过：标题曲每次开游戏都会响，能解锁 EXTRA 也说明这六面的 BGM 都响过了；其余曲目仍按实际播放记录。

## 系统

- **二段跳 / 土狼时间 / 跳跃缓冲**：手感经过调参，跳跃高约 4 格、跳远约 6.8 格。
- **低速移动与判定点**：按住 `Shift` 后移速降到 55%（飞行关 50%），角色身上会显示真正的受伤判定点——比立绘小得多。魔理沙的判定点比灵梦再小一点（平台关 6 → 5.4px，飞行关 4.2 → 3.6px）。
- **冲刺**：0.14 秒高速位移，可穿过敌人并造成伤害，有 0.55 秒冷却。
- **POWER 与火力**：POWER 为 0–16 的整数槽（HUD 上是 16 格短条），每 4 点提升一级火力（Lv.1–4），射击弹数依次为 1 / 2 / 3 / 5 发主弹。每颗 P 点 +1、击破杂兵 +1，飞行关擦弹也会缓慢累积；被弹落命后只保留一半 POWER。
- **1UP 累计**：POWER 条下方另有一条 `1UP` 计数，累计拾取 **99 点** POWER 就恢复 1 条残机，然后清零继续循环；只按「吃到多少点」累计，满槽时吃 P 也不浪费，放符卡掉火力也不会把进度抹掉；进度和 1UP 换来的残机会一路带进下一关，只有「重新挑战本关 / 续命重来」才清零回开局值。
- **自机弹道**：每次射击 = 固定直射的**主弹** + 每两轮补一发的角色专属**副弹**，两组子弹同时在场（参数集中在 `src/game/playerShots.js` 的 `SHOT_PROFILE`）：
  - **博丽灵梦 · 追踪御札**：副弹发射后自动咬住最近的敌人并修弯弹道，不区分 Boss 与杂兵，射程 1100 px、最大转向 7.4 rad/s；命中即消失，不穿透。锁定后不会每帧改目标，弹道不会抖动。
  - **雾雨魔理沙 · 穿透星弹**：副弹单发伤害为普通弹的数倍，命中后不消失、继续穿透后续目标——同一条弹对同一个目标只会结算一次；完全不追踪。
  - 子弹寿命约 1.7 秒，横向能飞过 1666 px（远超 1280 的屏宽），不再「打出去两步就消失」；主弹仍是窄扇直射，副弹则带一圈发光光环，一眼能分清。

- **符卡与火力下降**：POWER ≥ 6 时可放符卡，消耗 6 点（约四成槽）——清空全屏弹幕、对 Boss 造成 `(90 + 80 × 施放前火力等级) × 攻击倍率` 的伤害、并获得 2 秒无敌；同时播放全屏符卡 cut-in：白闪炸开压暗 → 立绘带残影破屏冲入 → 符卡名逐字砸出（斜光带扫过、符阵圆环扩张）→ 白光收束，约 1.15 秒；这期间世界先降到 45% 速度、再在 0.34 秒内平滑回升，游戏推进与判定照常。扣费后火力等级会立刻下降，之后的射击会变弱；这是「用火力换清屏」的取舍。灵梦与魔理沙各有两张符卡名轮换，配色随角色切换（粉 / 金）。
- **火力成长**：与上一条同一套 POWER 刻度，不存在独立的火力道具；吃 P 点就是最直接的强化手段。
- **Boss 战**：每位 Boss 的符卡数量依次为 2 / 3 / 4 / 5 / 6 / 8 / 10 张（合计 38 张），每张符卡一条独立血条，打空一张即切下一张，最后一张打空才算击败；单场战斗约 1.9–10 分钟，越往后的 Boss 血条越厚、弹幕越密。符卡名取自东方原作（6 面辉夜为「难题／神宝」成对，EX 芙兰为禁忌系符卡）。每场战斗用独立随机种子，招式按权重随机抽取、参数逐发抖动、走位随机，并会不定时追加计划外弹幕，同一场战斗不会两次一样。4 面起新增七类弹幕语法，弹型全部沿用游戏里的冰晶家族与东方原作的弹幕语汇（米弹 / 大玉 / 星弹 / 冰棱）：以玩家为圆心的结界围栏（`cage`，宝石弹围成一圈、留 1–4 个缺口，缺口缓慢转动）、雪花花瓣弧（`petal`）、大玉坠落并裂成米弹（`meteor`）、冰棱蛇行（`snake`）、泡弹漂浮后炸成小环（`mine`）、左右反向的交叉弧（`arc`）、双反向螺旋脉冲（`spiralPulse`）。
- **难度**：开始游戏后选择 E / N / H / L。四档的差别不只是「打几张符卡」，弹幕密度与弹速也逐档抬升（倍率以 N 为基准 1.00）：
  - E：5 面，通关不解锁 Extra；第 4、5 面各移除一张「难符卡」（该面血量最高的一张）。弹数 ×0.64、弹速 ×0.84、开火间隔 ×1.24，实际约 −50% 弹数 / −16% 弹速；单发速度上限 250 px/s、同屏弹数预算 520。
  - N：6 面，通关解锁 Extra；第 4、5、6 面各移除一张「难符卡」。弹数 ×0.96、弹速 ×1.00、开火间隔 ×1.02（几乎就是基准）；上限 340、预算 720。
  - H：6 面，完整符卡；弹数 ×1.16、弹速 ×1.10、开火间隔 ×0.93，约 +35% 弹数 / +10% 弹速；上限 400、预算 950。
  - L：6 面，完整符卡；弹数 ×1.45、弹速 ×1.22、开火间隔 ×0.80，约 +80% 弹数 / +22% 弹速；上限 470、预算 1180。
  - EX（隐藏，仅 Extra 关使用）：完整 10 张符卡、芙兰血量 ×1.8（有效约 4.82 万，约 10 分钟）、弹数 ×2.05、弹速 ×1.18、开火间隔 ×0.72；单发速度上限 520 px/s、同屏弹数预算 1600、环状弹幕最小弧距 22 px、环弹上限 72。三道护栏同步放宽（60%/80% 阈值改为 72%/92%，密度压力下限 0.45→0.62），避免加弹后被旧上限夹住。
  - 道中与杂兵走同一套梯度：飞行关自机狙的弹速 / 一次几发、平台关 flyer 的射击间隔 / 一次几发都按难度缩放，E 的敌机更慢更稀，L 更快更密。敌人也不止「妖精 + 飞行妖精」，但新增的全部按幻想乡的妖精 / 妖怪来设计，没有炮台、浮游炮、炸弹这类机械兵装：平台关新增御币妖精（挥御币蓄力突进，原作巫女的神乐道具）、蛛网妖精（土蜘蛛的丝网，闪现后打交叉星弹）、蝶妖精（三只小蝶绕身，环射时同时振翅）、提灯妖精（身下悬纸提灯，抛落鬼火雨）、魔法妖精（星之魔法阵，持续螺旋）；飞行关新增弓妖精（月牙弓 + 搭箭瞄准）、魔法妖精（星阵螺旋）、提灯妖精（青白鬼火抛落）、大妖精（背后薄光轮，进场后定点撒米弹），道中按面数用 V 字、纵列、夹击、交叉编队排布。
  - **分面密度（第 2–6 面统一收薄）**：在难度倍率之外再乘一层按关卡递减的系数，只影响「新开招式的弹数」与「道中齐射发数」，不改弹速与血量：2 面 ×0.80、3 面 ×0.76、4 面 ×0.72、5 面 ×0.68、6 面 ×0.64（1 面与 Extra 保持 ×1.00）。两层互乘后 N 的 6 面约 ×0.61、L 的 6 面约 ×0.93，后期不再靠堆弹量制造难度。
  - 特别下调的两张符卡：2 面第 2 张「蠢符『小虫风暴』」（扇 5 发 / 2 臂螺旋 / 2 发自机狙，峰值约 6.5 发/秒）与 3 面第 3 张「冻符『完美冻结』」（18×2 慢冰环 + 10 发快环 + 2 发自机狙，约 46 发/轮）。
  - 三道「有缝可解」护栏：环状弹幕按扩散半径限制圈内弹数（相邻两发弧距 ≥ 54 / 44 / 36 / 30 px），同屏弹数逼近预算就自动降密、超出就停火，单发速度一律夹在上限内。四档在符卡全开时实测仍留 200px 以上的横向空档，不会出现无解弹墙。
- **擦弹**：飞行关中贴近敌弹可累积 POW（东方传统机制）。

### 关卡机制

- **可崩塌砖**：砖块被踩上后抖动 0.5 秒塌陷，3.2 秒后复原；落命复活时整关砖块复位。桥面/天花板都可能是崩落砖。
- **水域游泳**：掉进水里下落速度降到约 1/4、水平速度略降；在水中按跳可上浮，但不能无限连跳（有划水冷却）。
- **冰面 / 蘑菇 / 藤蔓 / 单向木台**：冰面打滑、蘑菇有弹力、藤蔓可攀、单向台可以从下方穿过。
- **检查点与长图**：每 ~650 列一个存档点（灯笼），Boss 触发前自动存一次；长图只更新玩家附近 2400 px 内的敌人。
- **地形模板**：平台关由 20 余种地块模板拼接（本轮新增 11 种：多层台地、树冠高地、瀑布浮台、垂直塔楼、连续崩落桥、深谷、钟乳石洞窟、尖刺走廊、之字高地、地板多坑、岩檐），每个主题只取与自己相称的签名地形（神社的石阶、鸟居与庭院水潭，魔法森林的树冠、藤蔓与树根洞，雾之湖的瀑布浮冰，白玉楼的楼阁与黄泉洞，月都的碎裂桥、月面砖与月门），不再是一路平推的长直道；34 行的 stage5/6 把攀爬幅度从 3 行放宽到 8 行，垂直空间明显更多。

### 平台关 Boss 近战

平台关（1/2/3/5/6 面）的 Boss 不再只能远处对射——除了射击与符卡，现在有三条近战路线（飞行关不启用）：

- **破势条**：Boss 头顶一条细条，踩踏 / 冲刺撞击都会累积破势；打满立刻坠地硬直 2.2 秒（期间伤害 ×1.7、不出弹幕），头顶冒眩晕星与「STAGGER!」，之后破势上限每次 +25（上限 240），同场最多硬直 12 次。破势每 1 秒自然掉 7 点。
- **踩踏**：Boss 落地或硬直时，从上方踩中它身体顶部（约碰撞盒上沿 −8 ~ +30 px 的判定带），造成 `(96 + 20 × 当前符卡序号) × 攻击倍率` 伤害、破势 +30，自机被弹起（重给二段跳）。
- **冲刺撞击**：冲刺撞到 Boss 造成 `36 × 攻击倍率` 伤害、破势 +22，0.45 秒冷却；硬直期间撞击同样有效。
- **俯冲**：Boss 每 7~11 秒（血量越少越勤）会锁住自机位置蓄力 0.8 秒，再 0.32 秒俯冲砸地，落地向两侧喷出 2~3 道贴地冲击波弹（需跳起躲）；落地后 1.15 秒是踩踏窗口，且这段时间 Boss 没有接触伤害，可以贴身猛攻。
- 这一套只在 `platform` 模式生效，STG 关的 Boss 完全不受影响。

>
> 想复现某一场 Boss 弹幕，可在地址后加 `?seed=数字`，例如 `http://127.0.0.1:8137/index.html?seed=12345`。加了这个参数后全局随机数会换成由 seed 决定的确定性序列，并在每关开局、Boss 开战那一刻拨回起点，方便录像复盘或调试；会追踪玩家位置的弹幕仍随走位变化，所以复现的前提是操作也一致。不带参数时行为和以前一样。

## 技术说明

- **渲染**：标题画面使用一张预生成的插画背景 + 主角立绘（`src/art/gen/`），对白立绘同样来自预生成素材；其余场景、角色、弹幕全部程序化矢量绘制。天空使用渐变 + 光晕，瓦片按主题程序化生成，角色用贝塞尔曲线拼装。
- **弹幕性能**：每种子弹按「类型 × 颜色 × 尺寸」预渲染成离屏 canvas 缓存，运行时只做 `drawImage`，避免每帧创建上千个径向渐变。
- **Boss 随机弹幕**：随机只在「换招 / 开火 / 选移动点」时发生，帧循环里没有额外随机开销；随机量都有上下限（弹数 ≤1.3×、瞄准抖动 ≤0.2 rad），再用难度预算兜底：同屏弹数上限 E/N/H/L/EX = 520/720/950/1180/1600，单发速度上限 250/340/400/470/520 px/s，环状弹幕最小弧距 54/44/36/30/22 px；同屏弹数逼近预算时按 `pressure` 自动减发、超预算直接停火，保证任何难度都不会生成必死墙。
- **固定步长**：逻辑固定 60Hz，渲染可独立限帧，渲染时用 `alpha` 做插值，低帧率下动作依然平滑。
- **音乐**：曲库是纯数据（音符 + 鼓点数组），播放器每 25ms 前瞻 0.18s 调度振荡器，因此零音频文件、零加载等待。
  - 关卡 BGM 用各自 Boss 的原作主题曲改编：露米娅《妖魔夜行》（改为 six-段完整循环，106 秒）、莉格露《蠢々秋月》、琪露诺《おてんば恋娘》（整体 +2 半音、加高八度 sparkle 层与更密的鼓）、射命丸文《風神少女》、幽幽子《幽雅に咲かせ、墨染の桜》、辉夜《竹取飛翔》、芙兰《U.N.オーエンは彼女なのか？》（叠锯齿轮 sub-bass 与攻击层，鼓更密）。
  - 三首重点曲目的编排参数写在 `tools/midi2js.py` 的 `SONGS` 条目里（`arrange` 字段），改完重跑 `python tools/midi2js.py` 即可复现。
  - 标题曲《東方新紀行 ～ Chronicle of Gensokyo》是一首 14 作主题曲的融合 medley，顺序为 TH16《桜舞い散る天空》→ TH07《妖々夢 ～ Snow or Cherry Petal》→ TH08《永夜抄 ～ Eastern Night》→ TH09《花映塚 ～ Higan Retour》→ TH10《封印されし神々》→ TH11《地霊達の起床》→ TH06《赤より紅い夢》→ TH13《欲深き霊魂》→ TH14《不思議な不思議な道具達》→ TH15《宇宙巫女現る》→ TH12《青空の影》→ TH17（标题曲 MIDI 缺失，改用《Idolatrize World》）→ TH03《夢は時空を越えて》（梦时空，2 小节客串）→ TH18《虹を渡る幻想郷》，每作取 4 小节主旋律，统一到 150 BPM / D 自然小调关系圈，配器与鼓由 `tools/build_medley.py` 重写。主旋律层做过清晰化处理：合并同音反复、剔除经过性 16 分音符、半音外音归位、八度外音折回、尾音拉长，音区统一在 74–81；TH14 起的 5 段加高八度加厚，琶音在旋律密集的小节让位成四分音符；每个段落拐点前 1.5 拍铺一条上行衔接（音阶与和弦琶音交替，triangle 0.075），末音落在下一段首音上，低音同时补一个导向音，配合段尾军鼓过门与段首吊镲，避免硬切。试听版 `tools/build/title_chronicle_preview.wav`。
  - 失败《失われた道標》、结局《帰り道の夕暮れ》是按游戏名与剧情原创的曲子。
  - EXTRA 结局（W1 灵梦 / W2 魔理沙）用《魔法少女達の百年祭》的 8-bit 柔和版：`tools/build_extra_ending.py` 从 ZUN 原版 MIDI 取第 17–41 小节（留白 → 过门 → 主题旋律 → B 句，48 秒可循环），时间拉伸 1.25×（149 → 119 BPM）、整体降 2 半音、主音色方波 + 同度三角波、鼓只留底鼓 / 军鼓且力度腰斩；歌曲带 `soft: true`，播放时走 `audio.js` 的柔和总线（2.4kHz 低通 + 0.28s 短回声），同一个方波过这条总线频谱质心从 3.3kHz 落到 1.1kHz。改参数重跑 `python tools/build_extra_ending.py` 即可复现，试听版 `tools/build/endingW_preview.wav`。
  - 切歌会先掐掉旧曲已排期的音符，循环点由数据里的 `duration` 决定，接缝处无缝。
