# 东方新纪行 ～ Chronicle of Gensokyo

一款以《东方 Project》世界观为背景的同人动作游戏。纯原生 JavaScript + Canvas2D 实现，**零依赖、零构建**，用浏览器打开 `index.html` 就能玩。

---

## 内容概览

| 项目 | 内容 |
| --- | --- |
| 类型 | 2D 平台跳跃 + 弹幕射击 |
| 分辨率 | 1280×720（矢量绘制，任意窗口自适应缩放） |
| 主线 | 6 关（E 难度为 5 关，无第 6 面） |
| 难度 | E / N / H / L；E 不解锁 Extra，N 及以上通关解锁。Extra 关内部固定使用隐藏的 EX 档（不在菜单出现） |
| Extra | N 及以上难度通关主线后解锁：零火力起手的 14 分钟超长飞行道中 → 5:00 雷米莉亚中途战 → 14:00 芙兰朵露终盘；标题设置页可「重置进度」重新封闭 |
| 主角 | 博丽灵梦 / 雾雨魔理沙，可切换 |

## 故事

芙兰朵露被关在红魔馆地下，她想要一场「永不结束的祭典」。
这份无意识的愿望顺着「破坏一切」的力量渗进了幻想乡的地脉——
樱不落、雾不散、湖骤冻、山风停、花海不谢、月相乱。

沿途遇见的每一位，都不是元凶。她们只是被这场「不会结束的异变」困住的人。
线索一层层指向红魔馆地下那扇门。

## 操作

| 动作 | 键盘 |
| --- | --- |
| 移动 | `←` `→` / `A` `D` |
| 跳跃（可二段跳） | `空格` |
| 射击 | `Z` / `J` |
| 低速移动 / 显示判定点（按住） | `Shift` |
| 冲刺（冲刺中可撞伤敌人） | `K` / `C` |
| 符卡（消耗 50 POWER，清屏 + 高伤，火力下降） | `X` / `L` / `V` |
| 确认 | `Enter` |
| 暂停 / 设置菜单 | `Esc` / `P`，或点 HUD 右上角「设置」 |
| 暂停菜单 | `Esc` 继续、`S` 设置、`Q` 退出到标题 |
| 重开本关 | 暂停菜单 →「重新开始本关」，或 `R` |
| 静音 | `M` |
| 标题画面 | `S` 设置、`Q` 退出游戏 |

触屏设备会自动显示虚拟按键。

### 设置与键位

标题画面和暂停菜单都能进「设置」，两处内容一致（暂停来源会多一行「重新开始本关」，
标题来源会多一行「重置进度」）：

| 选项 | 说明 |
| --- | --- |
| 残机 | 1–4 条，`←` `→` 调整，下一局 / 重开本关时生效 |
| 全部静音 | 关掉所有声音（音效 + 音乐） |
| 背景音乐 / 音效 | 分别开关音乐与音效 |
| 音乐音量 / 音效音量 | `←` `→` 以 10% 为步进调整，0–100% 循环 |
| 屏幕震动 | 受击 / 爆发的镜头抖动 |
| 帧率上限 | 无上限 → 60 → 120 → 30 循环 |
| 按键设置 | 进入键位页：选中一项后按下新键即完成改键，`Del` 恢复默认 |
| 重置进度 | 仅标题画面的设置页有：二次确认后清掉通关记录，EXTRA 回到封闭状态（设置与键位保留） |
| 返回 | `Esc` 逐级返回，光标会停在刚才那一行 |

改键规则：每个动作有「主键 + 副键」，只改主键；新键若已被别的动作占用则自动互换，
若新键原本是别的动作的副键则清掉那条副键，保证任何时候都不会有两个动作抢同一个键。

设置保存在 `localStorage` 的 `hks.settings.v1`，键位保存在 `hks.keybinds.v1`，
通关进度保存在 `hks.progress.v1`（EXTRA 是否解锁 + 解锁时用的是哪位自机）；进 EXTRA 会强制换回那个人，刷新或重开浏览器都还在。

## 系统

- **二段跳 / 土狼时间 / 跳跃缓冲**：手感经过调参，跳跃高约 4 格、跳远约 6.8 格。
- **低速移动与判定点**：按住 `Shift` 后移速降到 55%（飞行关 50%），角色身上会显示真正的受伤判定点——比立绘小得多。魔理沙的判定点比灵梦再小一点（平台关 6 → 5.4px，飞行关 4.2 → 3.6px）。
- **冲刺**：0.14 秒高速位移，可穿过敌人并造成伤害，有 0.55 秒冷却。
- **POWER 与火力**：POWER 为 0–128 的连续值，每 32 点提升一级火力（Lv.1–4），射击弹数依次为 1 / 2 / 3 / 5 发。吃 P 点 +12，击破杂兵 +2（飞行关 +1.5），飞行关擦弹也会缓慢累积；被弹落命后只保留一半 POWER。
- **自机弹道**：两名主角不再是「同一套子弹换个颜色」，而是两套机制（参数集中在 `src/game/playerShots.js` 的 `SHOT_PROFILE`）：
  - **博丽灵梦 · 追踪御札**：发射后自动咬住最近的敌人并修弯弹道，不区分 Boss 与杂兵，射程 760 px、最大转向 6.4 rad/s；命中即消失，不穿透。锁定后不会每帧改目标，弹道不会抖动。
  - **雾雨魔理沙 · 扩散穿透星弹**：扇形散开（平射约 25° 总张角，仰射更开），单发伤害为普通弹的 **2 倍**，命中后不消失、继续穿透后续目标——同一条弹对同一个目标只会结算一次；完全不追踪。

- **符卡与火力下降**：POWER ≥ 50 时可放符卡，消耗 50 点——清空全屏弹幕、对 Boss 造成 `(90 + 80 × 施放前火力等级) × 攻击倍率` 的伤害、并获得 2 秒无敌。扣费后火力等级会立刻下降，之后的射击会变弱；这是「用火力换清屏」的取舍。
- **火力成长**：与上一条同一套 POWER 刻度，不存在独立的火力道具；吃 P 点就是最直接的强化手段。
- **Boss 战**：每位 Boss 的符卡数量依次为 2 / 3 / 4 / 5 / 6 / 8 / 10 张（合计 38 张），每张符卡一条独立血条，打空一张即切下一张，最后一张打空才算击败；单场战斗约 1.9–12 分钟，越往后的 Boss 血条越厚、弹幕越密。符卡名取自东方原作（6 面辉夜为「难题／神宝」成对，EX 芙兰为禁忌系符卡）。每场战斗用独立随机种子，招式按权重随机抽取、参数逐发抖动、走位随机，并会不定时追加计划外弹幕，同一场战斗不会两次一样。
- **难度**：开始游戏后选择 E / N / H / L。四档的差别不只是「打几张符卡」，弹幕密度与弹速也逐档抬升（倍率以 N 为基准 1.00）：
  - E：5 面，通关不解锁 Extra；第 4、5 面各移除一张「难符卡」（该面血量最高的一张）。弹数 ×0.64、弹速 ×0.84、开火间隔 ×1.24，实际约 −50% 弹数 / −16% 弹速；单发速度上限 250 px/s、同屏弹数预算 520。
  - N：6 面，通关解锁 Extra；第 4、5、6 面各移除一张「难符卡」。弹数 ×0.96、弹速 ×1.00、开火间隔 ×1.02（几乎就是基准）；上限 340、预算 720。
  - H：6 面，完整符卡；弹数 ×1.16、弹速 ×1.10、开火间隔 ×0.93，约 +35% 弹数 / +10% 弹速；上限 400、预算 950。
  - L：6 面，完整符卡；弹数 ×1.45、弹速 ×1.22、开火间隔 ×0.80，约 +80% 弹数 / +22% 弹速；上限 470、预算 1180。
  - EX（隐藏，仅 Extra 关使用）：完整 10 张符卡、芙兰血量 ×2.4（有效约 5.85 万）、弹数 ×2.05、弹速 ×1.18、开火间隔 ×0.72；单发速度上限 520 px/s、同屏弹数预算 1600、环状弹幕最小弧距 22 px、环弹上限 72。三道护栏同步放宽（60%/80% 阈值改为 72%/92%，密度压力下限 0.45→0.62），避免加弹后被旧上限夹住。
  - 道中与杂兵走同一套梯度：飞行关自机狙的弹速 / 一次几发、平台关 flyer 的射击间隔 / 一次几发都按难度缩放，E 的敌机更慢更稀，L 更快更密。
  - **分面密度（第 2–6 面统一收薄）**：在难度倍率之外再乘一层按关卡递减的系数，只影响「新开招式的弹数」与「道中齐射发数」，不改弹速与血量：2 面 ×0.80、3 面 ×0.76、4 面 ×0.72、5 面 ×0.68、6 面 ×0.64（1 面与 Extra 保持 ×1.00）。两层互乘后 N 的 6 面约 ×0.61、L 的 6 面约 ×0.93，后期不再靠堆弹量制造难度。
  - 特别下调的两张符卡：2 面第 2 张「蠢符『小虫风暴』」（扇 5 发 / 2 臂螺旋 / 2 发自机狙，峰值约 6.5 发/秒）与 3 面第 3 张「冻符『完美冻结』」（18×2 慢冰环 + 10 发快环 + 2 发自机狙，约 46 发/轮）。
  - 三道「有缝可解」护栏：环状弹幕按扩散半径限制圈内弹数（相邻两发弧距 ≥ 54 / 44 / 36 / 30 px），同屏弹数逼近预算就自动降密、超出就停火，单发速度一律夹在上限内。四档在符卡全开时实测仍留 200px 以上的横向空档，不会出现无解弹墙。
- **擦弹**：飞行关中贴近敌弹可累积 POW（东方传统机制）。

### 关卡机制

- **可崩塌砖**：砖块被踩上后抖动 0.5 秒塌陷，3.2 秒后复原；落命复活时整关砖块复位。桥面/天花板都可能是崩落砖。
- **水域游泳**：掉进水里下落速度降到约 1/4、水平速度略降；在水中按跳可上浮，但不能无限连跳（有划水冷却）。
- **冰面 / 蘑菇 / 藤蔓 / 单向木台**：冰面打滑、蘑菇有弹力、藤蔓可攀、单向台可以从下方穿过。
- **检查点与长图**：每 ~650 列一个存档点（灯笼），Boss 触发前自动存一次；长图只更新玩家附近 2400 px 内的敌人。

## 运行

```bash
# 任意静态服务器皆可，例如：
python -m http.server 8137
# 然后打开 http://127.0.0.1:8137/index.html
```

> 直接双击 `index.html` 可能因浏览器的 ES Module 同源策略而失败，建议用上面的方式起一个静态服务器（或使用 VS Code 的 Live Server）。
>
> 想复现某一场 Boss 弹幕，可在地址后加 `?seed=数字`，例如 `http://127.0.0.1:8137/index.html?seed=12345`。加了这个参数后全局随机数会换成由 seed 决定的确定性序列，并在每关开局、Boss 开战那一刻拨回起点，方便录像复盘或调试；会追踪玩家位置的弹幕仍随走位变化，所以复现的前提是操作也一致。不带参数时行为和以前一样。

## 技术说明

- **渲染**：标题画面使用一张预生成的插画背景 + 主角立绘（`src/art/gen/`），对白立绘同样来自预生成素材；其余场景、角色、弹幕全部程序化矢量绘制。天空使用渐变 + 光晕，瓦片按主题程序化生成，角色用贝塞尔曲线拼装。
- **弹幕性能**：每种子弹按「类型 × 颜色 × 尺寸」预渲染成离屏 canvas 缓存，运行时只做 `drawImage`，避免每帧创建上千个径向渐变。
- **Boss 随机弹幕**：随机只在「换招 / 开火 / 选移动点」时发生，帧循环里没有额外随机开销；随机量都有上下限（弹数 ≤1.3×、瞄准抖动 ≤0.2 rad），再用难度预算兜底：同屏弹数上限 E/N/H/L/EX = 520/720/950/1180/1600，单发速度上限 250/340/400/470/520 px/s，环状弹幕最小弧距 54/44/36/30/22 px；同屏弹数逼近预算时按 `pressure` 自动减发、超预算直接停火，保证任何难度都不会生成必死墙。
- **固定步长**：逻辑固定 60Hz，渲染可独立限帧，渲染时用 `alpha` 做插值，低帧率下动作依然平滑。
- **音乐**：曲库是纯数据（音符 + 鼓点数组），播放器每 25ms 前瞻 0.18s 调度振荡器，因此零音频文件、零加载等待。
