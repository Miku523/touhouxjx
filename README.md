# 东方新纪行 ～ Chronicle of Gensokyo

一款以《东方 Project》世界观为背景的同人动作游戏。纯原生 JavaScript + Canvas2D 实现，**零依赖、零构建**，用浏览器打开 `index.html` 就能玩。

## 在线游玩

打开 **<https://mikuascendlog.com/touhouxjx/>** 直接开玩，不用下载、不用安装、不用起本地服务器。

旧地址 <https://miku523.github.io/touhouxjx/> 会 301 跳到同一站点（GitHub Pages 自定义域名）。线上版本由 `main` 分支推送后自动重建；入口 CSS / JS 带 `?v=` 版本串，静态资源另有约 10 分钟 CDN 缓存，部署后仍看到旧界面时强刷一次（`Ctrl` + `Shift` + `R`）即可。

## 故事

幻想乡的夜停在了例大祭的前一天。灯不点、雾不散、湖上的冰不化、东边的天不亮——
不是夜太长，是有人把「天亮」留在了半路上。

红魔馆地下，被关了四百九十五年的芙兰朵露，十年前得到过一个约定：祭典的晚上，会有人在门口等她。
说那句话的人，那晚走到了门口，手举起来，没有敲。那年冬天，她死了。
今年是她的十回忌。她回到门外站着，一句话没说完，夜就不肯结束。

灵梦一路把亡霊往回送，却开始怀疑：送魂的仪式会把死者的话念给彼岸，念完，话就没了——
她一直以为自己的差事是结束，其实还差一次转达。
魔理沙一路把喜欢的东西借走、收藏，却在口袋里摸到十年前从神社库房借走的那枚御守：
她一直以为那是好收藏，其实那是没送出去的约定。

遗憾结局里，两位主角都没能把那句话带到门前；真结局里，她们没有做送魂的仪式——
她们替一个死去的人，敲了门。一年后的 EXTRA，是第二次：把「今年」变成「每年」的那一次。
两条线从开场到每一面的道中、Boss 前、Boss 后都有各自的对话，道中推进到 22% / 48% / 72% 还会各插入一段剧情。

## 结局

| 结局 | 条件 |
| --- | --- |
| END 01 送魂之夜（灵梦 · 遗憾） | E 任意方式通关；或 N/H/L 使用过续命后通关 |
| END 02 开门的理由（灵梦 · 真结局） | N/H/L 通关，且一次续命都没有用过 |
| END 03 替身之星（魔理沙 · 遗憾） | E 任意方式通关；或 N/H/L 使用过续命后通关 |
| END 04 归还之日（魔理沙 · 真结局） | N/H/L 通关，且一次续命都没有用过 |
| W1 每年的黎明（灵梦） | 在 EXTRA 选人页选择灵梦，并通关 EXTRA |
| W2 借来的座位（魔理沙） | 在 EXTRA 选人页选择魔理沙，并通关 EXTRA |

「续命」指游戏结束后选择「再战 Boss / 重新挑战本关」；暂停菜单里的「重新开始本关」不计入续命，但会从本关开头重来。
续命重来的口径：Boss 战进度不保留——「再战 Boss」会从该场 Boss 的第 1 张符卡、满血重新开始；火力回到本关开局值（不会归零，保证一接关就能正常开火、放符卡）；道中进度与已经击破的中途 Boss 不会重打。EXTRA 的续关按钮写成「从第 N 战继续」，直接回到连环战里死掉的那一场（该场从第 1 张符卡、满血重开，90 秒限时重新计时）。
E 难度只有 5 面，因此 E 通关必定进入遗憾结局，也不会解锁 EXTRA。
EXTRA 只有在达成 END 02 / END 04 后才会解锁；已经解锁后，后续再打遗憾结局也不会把它锁回去。EXTRA 通关只看主角，不受续命影响。
EXTRA 的主角按人分别解锁：灵梦达成 END 02 后能用灵梦进 EXTRA，魔理沙达成 END 04 后能用魔理沙进；两位都达成过，选人页里两张卡才同时可选（未解锁的那位灰显，点它会提示还差什么）。

| 动作 | 键盘 |
| --- | --- |
| 移动 | `←` `→` / `A` `D` |
| 跳跃（可二段跳） | `空格` |
| 射击 | `Z` / `J` |
| 低速移动 / 显示判定点（按住） | `Shift` |
| 冲刺（冲刺中可撞伤敌人） | `K` / `C` |
| 符卡（消耗 48 POWER，清屏 + 高伤 + 全屏 cut-in，火力下降） | `X` / `L` / `V` |
| 确认 | `Enter` |
| 暂停 / 设置菜单 | `Esc` / `P`，或点 HUD 右上角「设置」 |
| 暂停菜单 | `Esc` 继续、`S` 设置、`Q` 退出到标题 |
| 重开本关 | 暂停菜单 →「重新开始本关」，或 `R` |
| 隐藏跳关（试玩 / 排查） | 按住 `Shift` 再按 `1`–`6`：从主线第 1–6 面重新开一局 |
| 静音 | `M` |
| 标题画面 | `M` 音乐回忆室、`S` 设置、`Q` 退出游戏 |

触屏设备会自动显示虚拟手柄；桌面端不出现任何触屏控件，键位与手感保持不变。手机/平板/WebView/PWA/蓝牙手柄的完整说明见下方「移动端与多端」。

隐藏跳关当作「从那一面重新开一局」：残机回到设置值，续命次数、1UP 进度清零，火力回到开局值（16），开场与道中剧情一并跳过（Boss 照常登场）。跳关本身不写任何存档，跳进去之后正常打完仍按平常规则结算——所以 EASY 也能跳第 6 面，但 EASY 没有真结局；在按键设置页和音乐回忆室里这个组合键不生效。

### 设置与键位

标题画面和暂停菜单都能进「设置」，两处内容一致（暂停来源会多一行「重新开始本关」，
标题来源会多一行「重置进度」）：

| 选项 | 说明 |
| --- | --- |
| 残机 | 1–4 条，`←` `→` 调整，下一局 / 重开本关时生效 |
| 全部静音 | 关掉所有声音（音效 + 音乐） |
| 背景音乐 / 音效 | 分别开关音乐与音效 |
| 音乐音量 / 音效音量 | `←` `→` 以 10% 为步进调整，0–100% 循环 |
| 屏幕震动 | 受击 / 爆发的镜头抖动 |
| 帧率上限 | 无上限 → 60 → 120 → 30 循环 |
| 按键设置 | 进入键位页：选中一项后按下新键即完成改键，`Del` 恢复默认 |
| 触屏方案 | 仅触屏设备：摇杆 / 手势 / 按键，三选一，`T` 或 `←` `→` 切换 |
| 触屏震动 | 仅触屏设备：按下按钮 / 触发动作时的手机震动反馈（受系统省电模式影响） |
| 自定义按键布局 | 仅触屏设备：拖动虚拟按键到顺手的位置，`Y` 打开，可恢复默认 |
| 手柄震动 | 连接蓝牙手柄后可用：受击 / 放符卡 / 通关时的手柄震动 |
| 全屏 / 添加到桌面 | 仅触屏设备：浏览器全屏；iOS Safari 会弹「分享 → 添加到主屏幕」图示 |
| 重置进度 | 仅标题画面的设置页有：二次确认后清掉通关记录，两位主角的 EXTRA 解锁都会回到封闭状态（设置与键位保留） |
| 返回 | `Esc` 逐级返回，光标会停在刚才那一行 |

改键规则：每个动作有「主键 + 副键」，只改主键；新键若已被别的动作占用则自动互换，
若新键原本是别的动作的副键则清掉那条副键，保证任何时候都不会有两个动作抢同一个键。

设置保存在 `localStorage` 的 `hks.settings.v1`，键位保存在 `hks.keybinds.v1`，
通关进度保存在 `hks.progress.v1`（EXTRA 是否解锁 + 已在 EXTRA 解锁的主角列表；只有 END 02 / END 04 会写入或更新解锁）；
标题进 EXTRA 会先打开选人页，只在已解锁的主角里选；续命重试、重新挑战本关都沿用当前选中的那一位，刷新或重开浏览器都还在。
旧存档里只记了「最近一次达成真结局的那一位」：她照常可用，另一位按未解锁处理——用她再打一次真结局就会一起解开。

## 移动端与多端

同一份构建直接跑在桌面浏览器、iOS Safari / 主屏幕 PWA、Android Chrome、鸿蒙、微信 / QQ 内置浏览器上。桌面端的鼠标键盘操作与画面完全不变，所有移动端改动都只在触屏环境生效。

### 触屏虚拟手柄

触屏设备进入游戏后自动出现虚拟手柄，三种方案在「设置 → 操作 → 触屏方案」里切换（也可在游戏内点手柄上的齿轮，改完立即生效）：

| 方案 | 操作方式 |
| --- | --- |
| 摇杆（默认） | 左下虚拟摇杆控制移动（支持半推微调速度，不是只有八方向满速）；右侧射击 / 跳跃 / 低速 / 冲刺 / 符卡 / 暂停 |
| 手势 | 左半屏按住拖动移动、双击冲刺；右半屏按住射击、上滑跳跃、下滑低速、双指轻点放符卡 |
| 按键 | 左右方向键 + 右侧动作键，适合不习惯摇杆、或想要确定感更强的玩家 |

- 手柄齿轮里还能调**按键大小、不透明度、摇杆死区、8 方向吸附、震动反馈、手势提示**，并进入**布局编辑**把每个键拖到顺手的位置；布局按设备保存在本机。
- 摇杆走的是模拟量输入而不是把方向合成成「左/右」两个数字键，轻推可以慢速走位，和键盘手感接近。
- 所有触屏操作都同时驱动键盘/手柄共用的动作系统，改键、暂停、菜单导航、安卓返回键逻辑完全一致；对局中切到后台会自动暂停。
- 屏幕安全区（刘海 / 圆角 / 手势条）已适配，横屏提示用 `↻` 标在顶部；竖屏也能玩，但 16:9 画面会留黑边，建议横屏。旧版底部静态「虚拟按键」已退役，避免和手柄重复响应。

### 安装、全屏与内置浏览器

- **PWA / 添加到桌面**：`manifest.webmanifest` + `sw.js` 让游戏可以离线启动（首次加载后缓存并自动更新）。iOS Safari 点「分享 → 添加到主屏幕」，Android / 鸿蒙 Chrome 会弹底部安装条；安装条和 iOS 图示只在标题页出现，进入对局、设置、对话时自动收起，不会挡住按钮。
- **全屏**：设置里的「全屏」调用浏览器 Fullscreen API（iOS 不支持网页全屏，会提示用主屏幕方式启动）；从桌面图标启动时本身就是无地址栏的全屏。
- **微信 / QQ**：内置 WebView 里同样会识别为触屏并显示手柄；音频要等第一次点按后才会解锁（平台层已把首次手势接到 `audio.unlock()`），全屏能力取决于宿主，拿不到时会给出提示而不是卡死。
- **缓存排查**：调试或验收时给 URL 加 `?nosw=1` 可以跳过 Service Worker 注册，避免吃到旧缓存。

### 蓝牙手柄

支持标准映射的蓝牙 / USB 手柄（Gamepad API）：连上后设置页会显示「已连接」和手柄名，摇杆按模拟量驱动移动，十字键与 ABXY / 扳机映射到射击、跳跃、低速、冲刺、符卡、暂停；菜单和设置页也能用手柄导航。设置里的「手柄震动」控制受击 / 放符卡 / 通关时的震动强度，死区与映射可在 `hks.gamepad.v1` 里持久化。手柄和触屏、键盘可以同时使用，互不抢输入。

三方案操作细节、齿轮面板、安装与各端限制见 [docs/MOBILE_CONTROLS.md](docs/MOBILE_CONTROLS.md)；平台层实现与兼容矩阵见 [docs/PLATFORMS.md](docs/PLATFORMS.md)，蓝牙手柄细节见 [docs/GAMEPAD.md](docs/GAMEPAD.md)。

## 音乐回忆室

标题菜单里的「音乐回忆室 / MUSIC ROOM」是一间东方风格的试听室：左边是唱片目录，右边是唱机与解说。不用通关、不用进关卡，随时都能进来听。19 首曲子按故事顺序编号 01–19（标题 medley、1–6 面的道中与 Boss、EXTRA 道中与中途战、EXTRA Boss、失败、结局、EXTRA 结局）。

**没遇到过的曲子显示「？？？」**。只有真正在旅途中响过一次的旋律，才会在目录里露出曲名、时长和唱片标签；没听过的编号被薄雾罩着，右边只写「锁在旧留声机里」。选中它按 `Enter`（或用鼠标点一下）不会直接播放，而是先问一次：

> 第 06 号唱片被一层薄雾罩着。提前播放会揭晓曲名、人物与解说——要现在听吗？

选「播放」才会响，同时把曲名、人物、地点、原曲出处、解说与 BPM 一并揭晓；选「取消」就原样留着，下次再问。已经听过的曲子点一下直接播放，再按一次 `Enter` 抬针。

操作：`↑` `↓` 选曲、`←` `→` 换曲、`Enter` 播放 / 停止、`T` 试听 30 秒、`M` 静音、`Esc` 回标题。播放时唱片高光会转、频谱跳动，进度条与循环次数实时更新。

只想先尝一口、不打算把整首听完，就按 `T`（或点底栏「试听 30 秒」）：进度条上会多出一根细针，标出 30 秒收针的位置；底栏倒计时走到 0 会自动抬针并显示「试听结束」，中途再按一次 `T` 可以提前收针。试听同样会揭晓未遭遇的曲目（确认框里的按钮会变成「试听 30 秒」）。

「听过」的判定挂在 `AudioEngine` 的 `onSongStart` 上：标题曲（进标题就响）、关卡 BGM、失败 / 结局曲只要真正响过一次就记下，**不需要打赢**；设置里把音乐关掉时切歌不算数，等重新打开音乐真正开播才记。记录写在 `localStorage` 的 `hks.music.v1`，和通关进度分开——重置进度只清 EXTRA 解锁，已经点亮的唱片留在音乐室里。
老存档（这个功能上线前就在玩）第一次打开时会按 `hks.progress.v1` 里的 EXTRA 解锁状态，把标题曲与 1–6 面补记为听过：标题曲每次开游戏都会响，能解锁 EXTRA 也说明这六面的 BGM 都响过了；其余曲目仍按实际播放记录。

## 系统

- **二段跳 / 土狼时间 / 跳跃缓冲**：手感经过调参，跳跃高约 4 格、跳远约 6.8 格。
- **低速移动与判定点**：按住 `Shift` 后移速降到 55%（飞行关 50%），角色身上会显示真正的受伤判定点——比立绘小得多。魔理沙的判定点比灵梦再小一点（平台关 6 → 5.4px，飞行关 4.2 → 3.6px）。判定点显示期间，主弹扇形会急剧收束成一束（见下方「自机弹道」）。
- **冲刺**：0.14 秒高速位移，可穿过敌人并造成伤害，有 0.55 秒冷却。
- **POWER 与火力**：POWER 为 0–128 的整数槽（HUD 上满槽 128 点），每 24 点提升一级火力（Lv.1–5），射击弹数依次为 1 / 2 / 3 / 4 / 5 发主弹。每颗 P 点 +4（P 掉得稀，但一颗能看见血条跳一截）、击破杂兵 +1，飞行关擦弹也会缓慢累积；**每张 Boss 符卡按时击破（或存活卡坚持到点）给 1/4P**，该卡全程没受击、没落命再加 **1/2P**，基础 + 无伤合起来是 3/4P；被弹落命后只保留一半 POWER。
- **1UP 累计**：POWER 条下方另有一条 `1UP` 计数，累计 **99 点** 1UP 点数就恢复 1 条残机，然后清零继续循环；只按「入账多少点」累计，满槽时吃 P 也不浪费，放符卡掉火力也不会把进度抹掉；**擦弹每颗 +0.02 点**（POWER 的 0.075 收益保留，但不重复计入 1UP）、符卡结算的无伤 1/2P 与超时 +10 点也计入这条进度（满槽时基础 1/4P 与无伤 1/2P 合并成 131 点走同一次结算，视已有进度可能一帧给 2 条残机；带小数的进度显示到两位，如 12.34/99）；进度和 1UP 换来的残机会一路带进下一关，只有「重新挑战本关 / 续命重来」才清零回开局值。
- **STAGE 5 的开场补给**：这一面从妖梦舞台前面直接开场，出生点右侧沿路摆着 6 枚 P 点（24 点，正好一级火力）+ 1 枚 1UP；击破中途的魂魄妖梦后，再从空中落地 1 枚 1UP。**全部要自己走过去捡**，开战不再自动补火力。1UP 是独立绘制的粉色圆徽章（白环 + `1UP` 字样 + 心跳式粉光晕，悬空 9px 不被地面草叶挡住），和蓝白 P 符札一眼分得开；落地的道具会先掉到地面再转为可拾取。
- **STAGE 5 的音乐流程**：开场准备区（捡 P 点 / 1UP）与所有对话**全程静音**；妖梦登场、Boss 战开打时才起播五面道中曲《广有射怪鸟事》，妖梦击破后让这首**自己把这一轮放完，再用 5 秒淡出收尾**（不硬切、也不再循环），第二道中（呼吸区）安静下来；等幽幽子登场再切她的 Boss 曲《幽雅地绽放吧、墨染之樱》。其余各面仍是进关即放道中曲、Boss 登场切 Boss 曲。
- **自机弹道**：每次射击 = 固定直射的**主弹** + 每两轮补一发的角色专属**副弹**，两组子弹同时在场（参数集中在 `src/game/playerShots.js` 的 `SHOT_PROFILE`）：
  - **博丽灵梦 · 追踪御札**：副弹发射后自动咬住最近的敌人并修弯弹道，不区分 Boss 与杂兵，射程 1100 px、最大转向 7.4 rad/s；命中即消失，不穿透。锁定后不会每帧改目标，弹道不会抖动。
  - **雾雨魔理沙 · 穿透星弹**：副弹单发伤害为普通弹的数倍，命中后不消失、继续穿透后续目标——同一条弹对同一个目标只会结算一次；完全不追踪。
  - 子弹寿命约 1.7 秒，横向能飞过 1666 px（远超 1280 的屏宽），不再「打出去两步就消失」；主弹是带扩散的扇形直射（灵梦较窄、魔理沙明显更散），按住 `Shift` 低速时会急剧收束成一束，方便把火力钉在判定点正前方；副弹则带一圈发光光环，一眼能分清。

- **符卡与火力下降**：POWER ≥ 48 时可放符卡，消耗 48 点（约四成槽）——清空全屏弹幕、对 Boss 造成 `(90 + 80 × 施放前火力等级) × 攻击倍率` 的伤害、并获得 2 秒无敌；同时播放全屏符卡 cut-in：白闪炸开压暗 → 立绘带残影破屏冲入 → 符卡名逐字砸出（斜光带扫过、符阵圆环扩张）→ 白光收束，约 1.15 秒；这期间世界先降到 45% 速度、再在 0.34 秒内平滑回升，游戏推进与判定照常。扣费后火力等级会立刻下降，之后的射击会变弱；这是「用火力换清屏」的取舍。灵梦与魔理沙各有两张符卡名轮换，配色随角色切换（粉 / 金）。
- **火力成长**：与上一条同一套 POWER 刻度，不存在独立的火力道具；吃 P 点就是最直接的强化手段。
- **Boss 战**：主线关底 Boss 的符卡数量依次为 2 / 3 / 4 / 5 / 6 / 8 / 10 张（合计 38 张；第 5 面中途战的妖梦另算 3 张，EXTRA 的咲夜 4 张、雷米莉亚 2 张也各另算，全游戏实际 47 张），每张符卡一条独立血条，打空一张即切下一张，最后一张打空才算击败；**每张卡结算一次奖励**：按时击破、或存活卡坚持到点，各给 1/4P（32 POWER），该卡期间没受击也没落命再 +1/2P（64 POWER），两笔合成 3/4P 一次入账；火力满槽时 1/4P 与 1/2P 合并成 99+64=163 点走 1UP（一帧至少 1 条残机、余下的 64 点留在进度里），未满槽时则是 96 POWER 一次加进槽里；击破卡超时（限时内没打空）只给 +10 点（1UP 点数）；单场 Boss 的逐卡限时合计为 1:50 / 3:10 / 4:29 / 4:36 / 6:21 / 7:56，EXTRA 咲夜两场 3:00 + 中途 2:00 + 终盘 9:55 合计 14:55（详见「关卡与 Boss」表；2026-10-24 重定标，数值见 docs/BOSS_TIMING_TABLE.md），越往后的 Boss 血条越厚、弹幕越密。符卡名取自东方原作（6 面辉夜为「难题／神宝」成对，EX 芙兰为禁忌系符卡，最后一张换成这一夜的名字）。每场战斗用独立随机种子，招式按权重随机抽取、参数逐发抖动、走位随机，并会不定时追加计划外弹幕，同一场战斗不会两次一样。4 面起新增七类弹幕语法，弹型全部沿用游戏里的冰晶家族与东方原作的弹幕语汇（米弹 / 大玉 / 星弹 / 冰棱）：以玩家为圆心的结界围栏（`cage`，宝石弹围成一圈、留 1–4 个缺口，缺口缓慢转动）、雪花花瓣弧（`petal`）、大玉坠落并裂成米弹（`meteor`）、冰棱蛇行（`snake`）、泡弹漂浮后炸成小环（`mine`）、左右反向的交叉弧（`arc`）、双反向螺旋脉冲（`spiralPulse`）。

### 关卡机制

- **可崩塌砖**：砖块被踩上后抖动 0.5 秒塌陷，3.2 秒后复原；落命复活时整关砖块复位。桥面/天花板都可能是崩落砖。
- **水域游泳**：掉进水里下落速度降到约 1/4、水平速度略降；在水中按跳可上浮，但不能无限连跳（有划水冷却）。
- **冰面 / 蘑菇 / 藤蔓 / 单向木台**：冰面打滑、蘑菇有弹力、藤蔓可攀、单向台可以从下方穿过。
- **检查点与长图**：每 ~260 列一个存档点（灯笼），Boss 触发前自动存一次；长图只更新玩家附近 2400 px 内的敌人。
- **Boss 结界**：平台关（1/2/3/5/6 面）开战后自机被锁在 Boss 场里，左右都出不去——关底用关卡末尾 50 列平地，5 面妖梦用关卡中段挖出来的舞台；场地边界有一道很淡的竖直光幕提示（击破后消失，妖梦击破后要能走出口缓坡进第二道中）。落命复活 / 读档重试时若旧检查点留在场地外，会先被拉回场地并同步检查点。飞行关（4 面 / Extra）不设：滚动条在 Boss 战冻结，自机本来就回不到道中。
- **地形模板**：平台关由 20 余种地块模板拼接（本轮新增 11 种：多层台地、树冠高地、瀑布浮台、垂直塔楼、连续崩落桥、深谷、钟乳石洞窟、尖刺走廊、之字高地、地板多坑、岩檐），每个主题只取与自己相称的签名地形（神社的石阶、鸟居与庭院水潭，魔法森林的树冠、藤蔓与树根洞，雾之湖的瀑布浮冰，白玉楼的楼阁与黄泉洞，月都的碎裂桥、月面砖与月门），不再是一路平推的长直道；34 行的 stage5/6 把攀爬幅度从 3 行放宽到 8 行，垂直空间明显更多。

### 平台关 Boss 近战

平台关（1/2/3/5/6 面）的 Boss 不再只能远处对射——除了射击与符卡，现在有多条近战路线与两种可踩/可击破的场边元素（飞行关不启用）：

- **破势条**：Boss 头顶一条细条，踩踏 / 冲刺撞击都会累积破势；打满立刻坠地硬直 2.2 秒（期间伤害 ×1.7、不出弹幕），头顶冒眩晕星与「STAGGER!」，之后破势上限每次 +25，直到 240 封顶（初始上限 140）。破势每 1 秒自然掉 1 点；射击命中也会累积少量破势（按 Boss 血量归一化，单发上限 6 点）。
- **踩踏**：Boss 落地或硬直时，从上方踩中它身体顶部（约碰撞盒上沿 −8 ~ +30 px 的判定带），造成 `(96 + 20 × 当前符卡序号) × 攻击倍率` 伤害、破势 +30，自机被弹起（重给二段跳）。
- **冲刺撞击**：冲刺撞到 Boss 造成 `36 × 攻击倍率` 伤害、破势 +22，0.45 秒冷却；硬直期间撞击同样有效。
- **冲撞反击窗口**：Boss 周期性蓄力 0.55 秒后横向冲撞 0.32 秒，随后 0.75 秒僵直白闪并冒出「COUNTER!」——这段时间冲刺撞击伤害 ×1.5、破势 ×1.6（约 26 点），是从正面抢节奏的主要窗口。
- **俯冲窗口**：Boss 每 7~11 秒（血量越少越勤）会锁住自机位置蓄力 0.8 秒，再 0.32 秒俯冲砸地，落地向两侧喷出 2~3 道贴地冲击波弹（需跳起躲）；落地后约 1 秒是踩踏窗口（破势 ×1.8、踩踏伤害 ×1.4），且这段时间 Boss 没有接触伤害，可以贴身猛攻。
- **落地破势球**：Boss 每 7.5~11.5 秒抛下 2 颗发光的破势球，踩中即 +18 破势并弹起；Boss 硬直期间踩球伤害 ×1.5。
- **硬直放大器**：硬直期间每 8 次射击命中追加 `14 × 攻击倍率` 伤害、踩踏伤害 ×1.35，鼓励把火力全灌进 2.2 秒窗口。
- **STG 关互动（4 面起，Extra 不启用）**：距 Boss 300 px 内持续 1.2 秒进入「贴身压制」（射击伤害 ×1.10）；Boss 头顶会周期性显形可击破的符卡核心（28~36 秒一轮、存活 7 秒），持续射击打爆可造成额外伤害并让 Boss 停火 1.1 秒。
- 以上近战与互动只在 `platform` 模式生效；STG 关只有上述两项，Extra 关完全保持原版。

- **道中弹速分档**：飞行关道中杂兵的齐射不再整屏一个速度——同一轮弹幕按发序轮换速度倍率（`stgSpeedBands`），E 保持同速、N ±8%、H ±14%、L ±20%，EXTRA 走隐藏 EX 档的快 / 中 / 慢三层（1.28 / 0.95 / 0.72）：螺旋妖精变成三条不同转速的螺线，环弹与扇形也快慢混编，抛物雨分快落与慢飘两档。快档仍统一被 `bulletSpeedCap` 夹住，不会破护栏；`_ex_speed_bands_probe.mjs` 实测每一轮齐射都含至少两种速度。

python -m http.server 8137

> 直接双击 `index.html` 可能因浏览器的 ES Module 同源策略而失败，建议用上面的方式起一个静态服务器（或使用 VS Code 的 Live Server）。
>
> 想复现某一场 Boss 弹幕，可在地址后加 `?seed=数字`，例如 `http://127.0.0.1:8137/index.html?seed=12345`。加了这个参数后全局随机数会换成由 seed 决定的确定性序列，并在每关开局、Boss 开战那一刻拨回起点，方便录像复盘或调试；会追踪玩家位置的弹幕仍随走位变化，所以复现的前提是操作也一致。不带参数时行为和以前一样。

## 部署

线上就是 GitHub Pages 托管的仓库根目录（`main` 分支 → `/`，无构建步骤）：

```bash
git push origin main   # 推送后 Pages 自动重建，约 1 分钟生效
```

- 线上入口只依赖 `index.html`、`manifest.webmanifest`、`sw.js` 和 `src/`；`docs/`、`tools/` 只留在仓库，不影响加载。`.nojekyll` 关闭 Jekyll 处理，避免下划线开头的目录被吞。
- 改动 `src/` 里任意脚本或样式后，三处版本串必须一起升：`index.html` 的 5 个 `?v=`、`src/ui/platform.js` 的 `PLATFORM_VERSION`、`sw.js` 的 `CACHE_VERSION`（以及 `PRECACHE` 里的 `platform.css?v=`）。入口文件自身也有 10 分钟 CDN 缓存，版本串能让旧访客立刻拿到新代码，不会出现「新 HTML + 旧 JS」的错配，也不会被旧 Service Worker 缓存套住。`src/` 里那些被 import、不在 `?v=` 清单里的内层模块（如 `src/engine/audio.js`）由 Service Worker 兜底：JS / CSS 请求一律网络优先、断网才回退缓存，所以发版后刷新一次就是新代码；不要改回 `stale-while-revalidate`，那会先吐旧模块、要刷两次才更新，正好造成「新 HTML + 旧模块」的错配。
- 改素材时别手写二进制：`src/art/gen/` 的图片按 `python tools/optimize_art_webp.py` 重新生成 `.webp`（代码里引用 `.webp`），三首预渲染曲按 `python tools/optimize_audio_mp3.py` 重新转码；`src/` 的 import 关系一变，还要重跑 `python tools/gen_modulepreload.py --write`，否则 `index.html` 里的 modulepreload 清单会过期。国内访问的现状、实测数据与复测方法见 `docs/NETWORK_CN.md`。
- 线上响应头是 `Cache-Control: max-age=600`；核对线上是否已是新版本，可直接对比哈希：

```bash
curl -s https://mikuascendlog.com/touhouxjx/src/main.js | sha1sum
git show HEAD:src/main.js | sha1sum      # 忽略 CRLF 时用 tr -d '\r'
```

## 技术说明

- **渲染**：人物全部使用 `src/art/gen/` 下的 AI 生成素材——标题背景、自机六状态动作帧、Boss 战斗 / 对话立绘、五色妖精；缺图时只铺柔光占位，不再有任何程序化矢量或剪影人物。场景与弹幕仍为 Canvas2D 程序化绘制：天空用渐变 + 光晕，瓦片按主题生成。
- **弹幕性能**：每种子弹按「类型 × 颜色 × 尺寸」预渲染成离屏 canvas 缓存，运行时只做 `drawImage`，避免每帧创建上千个径向渐变。
- **Boss 随机弹幕**：随机只在「换招 / 开火 / 选移动点」时发生，帧循环里没有额外随机开销；随机量都有上下限（弹数 ≤1.3×、瞄准抖动 ≤0.2 rad），再用难度预算兜底：同屏弹数上限 E/N/H/L/EX = 520/720/950/1180/1600，单发速度上限 250/340/400/470/520 px/s，环状弹幕最小弧距 54/44/36/30/22 px；同屏弹数逼近预算时按 `pressure` 自动减发、超预算直接停火，保证任何难度都不会生成必死墙。
- **固定步长**：逻辑固定 60Hz，渲染可独立限帧，渲染时用 `alpha` 做插值，低帧率下动作依然平滑。
- **音乐**：曲库是纯数据（音符 + 鼓点数组），播放器每 25ms 前瞻 0.18s 调度振荡器，因此零音频文件、零加载等待（只有 EXTRA 道中曲、U.N. 与结局曲例外，改成离线渲染的 WAV，见下）。
