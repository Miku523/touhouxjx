# 东方新纪行 ～ Chronicle of Gensokyo

一款以《东方 Project》世界观为背景的同人动作游戏。纯原生 JavaScript + Canvas2D 实现，**零依赖、零构建**，用浏览器打开 `index.html` 就能玩。

---

## 内容概览

| 项目 | 内容 |
| --- | --- |
| 类型 | 2D 平台跳跃 + 弹幕射击 |
| 分辨率 | 1280×720（矢量绘制，任意窗口自适应缩放） |
| 主线 | 6 关（E 难度为 5 关，无第 6 面） |
| 难度 | E / N / H / L；E 不解锁 Extra，N 及以上通关解锁 |
| Extra | N 及以上难度通关主线后解锁，纯 Boss 弹幕战 |
| 主角 | 博丽灵梦 / 雾雨魔理沙，可切换 |
| 残机 | 1–4 条，在设置页内调整，下一局生效 |
| 帧率 | 无上限 / 30 / 60 / 120，设置页内切换 |
| 音乐 | 全部 WebAudio 实时合成，无音频文件 |

## 故事

芙兰朵露被关在红魔馆地下，她想要一场「永不结束的祭典」。
这份无意识的愿望顺着「破坏一切」的力量渗进了幻想乡的地脉——
樱不落、雾不散、湖骤冻、山风停、花海不谢、月相乱。

沿途遇见的每一位，都不是元凶。她们只是被这场「不会结束的异变」困住的人。
线索一层层指向红魔馆地下那扇门。

## 操作

| 动作 | 键盘 |
| --- | --- |
| 移动 | `←` `→` / `A` `D` |
| 跳跃（可二段跳） | `空格` |
| 射击 | `Z` / `J` |
| 加速移动（按住） | `Shift` |
| 冲刺（冲刺中可撞伤敌人） | `K` / `C` |
| 符卡（消耗 POW，清屏 + 高伤） | `X` / `L` / `V` |
| 确认 | `Enter` |
| 暂停 / 设置菜单 | `Esc` / `P`，或点 HUD 右上角「设置」 |
| 暂停菜单 | `Esc` 继续、`S` 设置、`Q` 退出到标题 |
| 重开本关 | 暂停菜单 →「重新开始本关」，或 `R` |
| 静音 | `M` |
| 标题画面 | `S` 设置、`Q` 退出游戏 |

触屏设备会自动显示虚拟按键。

### 设置与键位

标题画面和暂停菜单都能进「设置」，两处内容一致（暂停来源会多一行「重新开始本关」）：

| 选项 | 说明 |
| --- | --- |
| 残机 | 1–4 条，`←` `→` 调整，下一局 / 重开本关时生效 |
| 全部静音 | 关掉所有声音（音效 + 音乐） |
| 背景音乐 / 音效 | 分别开关音乐与音效 |
| 音乐音量 / 音效音量 | `←` `→` 以 10% 为步进调整，0–100% 循环 |
| 屏幕震动 | 受击 / 爆发的镜头抖动 |
| 帧率上限 | 无上限 → 60 → 120 → 30 循环 |
| 按键设置 | 进入键位页：选中一项后按下新键即完成改键，`Del` 恢复默认 |
| 返回 | `Esc` 逐级返回，光标会停在刚才那一行 |

改键规则：每个动作有「主键 + 副键」，只改主键；新键若已被别的动作占用则自动互换，
若新键原本是别的动作的副键则清掉那条副键，保证任何时候都不会有两个动作抢同一个键。

设置保存在 `localStorage` 的 `hks.settings.v1`，键位保存在 `hks.keybinds.v1`，刷新或重开浏览器都还在。

## 系统

- **二段跳 / 土狼时间 / 跳跃缓冲**：手感经过调参，跳跃高约 4 格、跳远约 6.8 格。
- **冲刺**：0.14 秒高速位移，可穿过敌人并造成伤害，有 0.55 秒冷却。
- **POW 与符卡**：击破敌人、吃 P 点积累 POW；满 50 可放符卡，清空全场弹幕并造成 90 伤害。
- **火力成长**：POW 越高射击弹数越多（1–4 发）。
- **Boss 战**：每位 Boss 的符卡数量依次为 2 / 3 / 4 / 5 / 6 / 8 / 10 张（合计 38 张），每张符卡一条独立血条，打空一张即切下一张，最后一张打空才算击败；单场战斗约 2.5–16 分钟，越往后的 Boss 血条越厚、弹幕越密。符卡名取自东方原作（6 面辉夜为「难题／神宝」成对，EX 芙兰为禁忌系符卡）。每场战斗用独立随机种子，招式按权重随机抽取、参数逐发抖动、走位随机，并会不定时追加计划外弹幕，同一场战斗不会两次一样。
- **难度**：开始游戏后选择 E / N / H / L。
  - E：5 面，通关不解锁 Extra；第 4、5 面各移除一张「难符卡」（该面血量最高的一张）。
  - N：6 面，通关解锁 Extra；第 4、5、6 面各移除一张「难符卡」。
  - H / L：6 面，完整符卡；H / L 的 Boss 血量、弹幕密度与速度依次提高。
- **擦弹**：飞行关中贴近敌弹可累积 POW（东方传统机制）。

## 文件结构

```
index.html              入口（画布 + DOM 叠加 UI）

  main.js               游戏主类：状态机、菜单、流程编排

  engine/
    loop.js             固定步长主循环（逻辑 1/60 + 渲染限帧 + 插值）
    renderer.js         整数倍缩放与 DPR 处理
    input.js            键盘 / 触屏输入（边沿检测、动作映射）

  game/

    bullets.js          弹幕池（离屏精灵缓存）

    level.js            关卡解析与瓦片碰撞
    difficulty.js       难度配置：面数、符卡裁剪、血量 / 弹幕倍率
    dialogue.js         对话框（打字机 + 立绘画布）
    story.js            全部剧本
    hud.js              HUD 与横幅
  assets/
    levels.js           七关地图数据（字符地图）

    chars.js            自机角色程序化矢量绘制
```

## 运行

```bash
# 任意静态服务器皆可，例如：
python -m http.server 8137
# 然后打开 http://127.0.0.1:8137/index.html
```

> 直接双击 `index.html` 可能因浏览器的 ES Module 同源策略而失败，建议用上面的方式起一个静态服务器（或使用 VS Code 的 Live Server）。
>
> 想复现某一场 Boss 弹幕，可在地址后加 `?seed=数字`，例如 `http://127.0.0.1:8137/index.html?seed=12345`；同一 seed 的弹幕轨迹完全一致，方便录像复盘或调试。

## 技术说明

- **渲染**：标题画面使用一张预生成的插画背景 + 主角立绘（`src/art/gen/`），对白立绘同样来自预生成素材；其余场景、角色、弹幕全部程序化矢量绘制。天空使用渐变 + 光晕，瓦片按主题程序化生成，角色用贝塞尔曲线拼装。
- **弹幕性能**：每种子弹按「类型 × 颜色 × 尺寸」预渲染成离屏 canvas 缓存，运行时只做 `drawImage`，避免每帧创建上千个径向渐变。
- **Boss 随机弹幕**：随机只在「换招 / 开火 / 选移动点」时发生，帧循环里没有额外随机开销；随机量都有上下限（弹数 ≤1.3×、瞄准抖动 ≤0.2 rad、全场弹数超过 1180 时停止发射），保证不会生成必死墙。
- **固定步长**：逻辑固定 60Hz，渲染可独立限帧，渲染时用 `alpha` 做插值，低帧率下动作依然平滑。
- **音乐**：WebAudio 振荡器合成，八小节循环的 ZUN 风旋律。
