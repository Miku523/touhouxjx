# 桌面鼠标操作方案（WASD + 鼠标）

> 面向玩家和后续维护者。默认仍然是「键盘」方案，键位、手感、画面完全不变；这里只是多一种可选的鼠标方案，随时可以切回去。
>
> 相关：[`README.md`](../README.md) 的「操作」「设置与键位」、[`docs/MOBILE_CONTROLS.md`](MOBILE_CONTROLS.md)（触屏与多端）、[`docs/GAMEPAD.md`](GAMEPAD.md)（蓝牙手柄）。
>
> 实现：`src/engine/input.js`（`setScheme()` / `setMouseButton()` / 画布鼠标绑定）、`src/main.js`（设置行、`_applyControlScheme()` / `_cycleControlScheme()`）。

---

## 1. 两套操作方式

| 方案 | 移动 | 射击 | 符卡 | 键盘动作键 |
| --- | --- | --- | --- | --- |
| **键盘**（默认） | `←` `→` / `A` `D` | `Z` / `J` | `X` / `L` | 全部照旧 |
| **WASD + 鼠标** | `W` `A` `S` `D` | 鼠标左键（按住持续射击） | 鼠标右键 | 全部照旧，与鼠标并存 |

「键盘」方案一个键都没动：

- `←` `→` / `A` `D` 移动，`↑` `↓` 瞄准 / 菜单
- `空格` 跳跃（可二段跳），`Shift` 低速（显示判定点）
- `Z` / `J` 射击，`X` / `L` 符卡
- `K` / `C` 冲刺，`Esc` 暂停 / 返回

「WASD + 鼠标」方案只**增加**鼠标这一路输入：`W` `A` `S` `D` 移动，鼠标左键 = 射击（按住一直开火），鼠标右键 = 符卡（释放浮卡）。其余键盘按键在两种方案下完全一样，改键页也共用同一份键位。

---

## 2. 怎么切换

1. 标题画面或暂停菜单进入「设置」。
2. 找到「游戏」组里的「操作方式」一行。
3. 用 `←` `→` / `Enter` 在分段控件 `[键盘]` `[WASD + 鼠标]` 之间切换，或直接按快捷键 `U`。
4. 改完立即生效，不用退出设置；关掉设置后也保持。

设置写在 `localStorage['hks.settings.v1']` 的 `controlScheme` 字段里（`'keys'` / `'wasd-mouse'`），下次启动沿用。旧存档没有这个字段、或值不合法时回落到 `'keys'`，行为与旧版一致。

## 3. 鼠标方案的行为细节

- **射击判定**：只在游戏画布（`#game`）上按下鼠标左键才算射击；在 HUD、菜单按钮上点击仍是普通 UI 点击，不会顺手开火。
- **按住连发**：左键按住期间持续射击，不需要连点，和键盘按住 `Z` / `J` 一致。
- **符卡**：右键按下即释放符卡（消耗 POWER、清屏 + 高伤 + 全屏 cut-in），规则与键盘 `X` / `L` 完全一致；只在满足释放条件时生效。
- **松开与失焦**：松开挂在 `window` 上，指针移出画面甚至移出窗口也能正常松开；窗口失去焦点时会松开全部按住状态，不会出现「按着不放」的粘键。
- **切方案时松手**：切换操作方式的那一刻会主动松开鼠标按键，避免切回来时还卡着射击。
- **右键菜单**：鼠标方案下，游戏画布上的浏览器右键菜单被抑制（`contextmenu` 被 `preventDefault`）；切回键盘方案后不再拦截，浏览器行为恢复原样。
- **指针形状**：鼠标方案下对局画布的光标变为十字准星（`crosshair`），方便对准；菜单与设置页仍是普通光标。
- **触屏 / 触控笔**：只认鼠标指针，触屏与触控笔的指针事件不会触发鼠标射击，仍然走虚拟手柄。

## 4. 只在桌面出现

- 「操作方式」这一行**只在桌面环境显示**：纯触屏设备（手机 / 平板）没有这一行，触屏方案见 [`docs/MOBILE_CONTROLS.md`](MOBILE_CONTROLS.md)。
- 接蓝牙键盘 / 鼠标的平板仍按触屏设备处理，不会出现这行。
- 「操作说明」页会跟着当前方案换文案：鼠标方案下「射击」「符卡」两行的键帽显示为 `鼠标左键` / `鼠标右键`；键盘方案仍显示 `Z` / `J` 与 `X` / `L`。
- 菜单导航仍然用键盘（方向键 / `Enter` / `Esc`）；鼠标点击菜单按钮照常可用，两种方案下都不变。

---

## 5. 存档与默认值

- 存档键：`localStorage['hks.settings.v1']` 的 `controlScheme` 字段。
- 合法值：`'keys'`（默认）/ `'wasd-mouse'`；缺省、乱码或旧存档读到的其它值一律按 `'keys'` 处理。
- 和残机、音量、帧率上限等设置存在一起；设置页「重置进度」只清通关记录，不动这一项。
- 键位仍单独存在 `localStorage['hks.keybinds.v1']`，两种方案共用，不会因为切方案被重置。

---

## 6. 已知限制

- 只认鼠标左键 / 右键；滚轮、中键、侧键不参与游戏。
- 鼠标方案不改变任何键盘键位，也不提供「鼠标打飞机」那种跟随光标的移动方式，移动仍然是 `W` `A` `S` `D`。
- 触屏设备不会出现该选项；想在平板上用鼠标，仍按触屏方案操作。
- 右键菜单只在游戏画布上被抑制；页面其它区域的浏览器右键菜单不受影响。
- 鼠标只在游戏画布上生效，菜单与设置页的鼠标点击逻辑与方案无关。
