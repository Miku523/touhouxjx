## 0. 一句话

**幻想乡的夜，停在了例大祭的前一天。**

因为十年前，有一位巫女答应过红魔馆地下的孩子：「祭典的晚上，我在门口等你。」  
她来了，站在门口，一直没有敲门。  
死人不敲的门，活着的人替她敲。

这句话里换掉了三样东西：

- 按住世界的，不再是「一个孩子无意识的愿望」，而是**一个死者不敢敲门的手**；
- 玩家的身份，不再是「来收尾的外人」，而是**被托付的那张嘴**；
- 遗憾的落点，不再是「没人问过她叫什么」，而是**话明明说出来了，却说错了方向**。

## 1. 为什么要换（诊断）

### 1.1 旧剧本的四个问题

1. **遗憾不在玩家手里。** 旧的收束是「打倒六个按住『结束』的妖怪，把春天还回去」——遗憾属于芙兰（等不到）、属于灵梦（总在收尾），却不属于玩家。同人研究里那条硬规则是反过来的：*后劲来自「这件事是我亲手做的」*（`RESEARCH_DOUJIN.md` C 节）。
2. **没有人有私心，所以打完不疼。** 旧版六个 Boss 是「愿望的守卫或知情者」，都是好人，但**没有一个在为自己留住什么**。她们输了就输了，玩家赢了就走。没有代价的胜利，不会留下遗憾。
3. **两个主角的伤口是设定，不是选择。** 「灵梦总负责结束」「魔理沙什么都留不住」这两句写在文件头注释里（`src/game/story.js:18-19`），但玩法上没有任何一刻逼她们选。玩家读到的是一句性格描述，不是一次失去。
4. **结局的差异靠一句旁白交代。** 旧 ED1 里，门开没开只体现在「在门口站了一会儿／回来了」（`src/game/endings.js` ed1 shot2）。玩家没有参与那个决定，所以那份遗憾是**别人**的。

### 1.2 必须保留的（已验证是这套骨架的资产）

| 保留项                            | 理由                                                |
| ------------------------------ | ------------------------------------------------- |
| 六面动线：神社→森林→湖→山→冥界→月都→红魔馆地下     | 关卡、背景、音乐、Boss 顺序全部复用，改造成本最低                       |
| 全部 Boss 与中 Boss                | 立绘（`src/art/roster.js`）、符卡、AI 都已存在                |
| 「没有恶人」的官方气质                    | `RESEARCH_CANON.md` B 节：TH14/16/17 的元凶在官方结局里都不被惩罚 |

| 双主角 × 三档结局（回味/真/Extra）与 0 续命判定 | `src/main.js:1322`，不动                             |
| 每面五槽、每段 6–15 句的节奏              | `src/main.js:1468-1489`，不动                        |

### 1.3 必须删掉的（旧梗不能再用）

- **苹果糖 / 不会融化的蓝糖**（旧 ED1）：糖类信物过甜，且已被用尽。新信物改用**御守**与**神乐铃**。
- **「灵梦连那个名字都没问过」**（旧 ED1 的落点）：这是一记好拳，但已经打过了。新版的落点&#x662F;**「话送到了没有」**——同名母题换一个角度，避免自我重复。
- **芙兰「许愿让祭典不要结束」作为主因**：把元凶从「孩子」换成「死者的犹豫」，芙兰则退回成**什么都不知道、只是在等的人**。这样她才可怜，而不是可怕。

## 2. 新世界观规则（五条，全部可以被玩家看见）

### 规则一 · 夜停在祭典前夜

幻想乡的夜停在例大祭的前一天。灯笼挂满了石阶，屋台支好了，布也盖好了，谁也不开张——因为「点灯」是祭典开始之后的规矩。

不是太阳不来。是**每一天的黎明，都在半路上被什么东西吃掉了**（一面会告诉你是什么）。幻想乡的春天因此停住：祭典不开，春天就翻不过去，樱也就一直落不下来。

### 规则二 · 十回忌的一夜

死者死后第十年的忌日，可以回人间走一夜。只一夜，用来说完没说完的话。过了这一夜，就再没有下一次。

今年，正好是**博丽先代巫女的十回忌**。

> 设定说明：「博丽先代」在官方设定里没有具体人物（`RESEARCH_CANON.md` E 节），本作按二创处理：不给她个人名字，只称「先代」「博麗」。她的死因是病，没有凶手——遗憾不需要坏人。

**为什么是一夜，变成了七十天。** 两条线咬在一起：

1. 十年前那个祭典前夜，先代已经走不动了，她向辉夜借了「再多一夜」——**用这一夜走到红魔馆门口**。她走到了，手举起来，没敲。这一夜她没有还，也还不上了（那年冬天她死了）。
2. 今年是十回忌，她终于能回来走这一夜。可她要办的事还没办完——**没说完的话会把夜留住**。她站在门口，一夜就一天一天地叠下去，叠到了第七十天。

所以天亮有两个条件：她的约要被了结，**借来的那一夜也要有人去还**（那是辉夜那一关的活）。

### 规则三 · 死人的话，要有活人的嘴

亡霊能听、能点头、能指路，但她的声音传不到活人耳朵里。要让她的话被听见，得有一个活人把话**说出去**。

神社的送魂仪式就是这么做的：巫女把死者的最后一句话念出来，念给彼岸听。念完，那句话就从这边消失了。

**这是全剧最重要的一条规则：仪式会把话带走。**  
送魂没有错。正因为没有错，才让人遗憾。

### 规则四 · 红魔馆的门只对两种东西开

雷米莉亚立的规矩：**这扇门，只对「敲了门的人」和「约定本身的信物」开门。** 死人敲不响，半死的人也敲不响。

- 先代站在门前七十夜，一次也没敲。不是敲不响——是**不敢**。敲了，就等于承认「我做不到带你出去」。
- 灵梦用续命回来（借命），手是凉的，敲上去没有声音 → 她只能做她最擅长的事：送。
- 魔理沙手是热的，她敲得响。但她口袋里那枚御守，是约定本身的信物——她**不知道**，于是选了别的礼物。

> **续命 = 遗憾** 这条旧机制，这次给了它一句台词级的说法（雷米莉亚闻得出「死味」），但不写成硬设定。玩家感受到的应该是「这次我没能敲开门」，而不是去推演规则漏洞。

### 规则五 · 逢魔时把路弯了

夜停住的时候，**去红魔馆的路会绕回神社**。灵梦试过三次，第三次飞回来的时候，人已经在石阶底下了。

要通路，得先把「结」解开：黎明被谁吃了、雾被谁按住了、东边的天被谁冻住了。每解开一个结，路就往前通一段。这不是设计上的拖延，是「逢魔时」本身的样子——**天没有走到那一边，路也走不到那一边**。

（这条规则同时解决一个结构问题：为什么玩家不直接飞去红魔馆把鬼送走。）

## 5. 双主角：这一次伤口是有形状的

### 5.1 灵梦 · 「送」与「传」

- **设定（可见）**：神社的巫女负责送灵。她把送灵当差事，做得干净、准时、从不迟到。她记得每个死者的忌日，记不住名字。
- **裂缝（一段）**：露米娅问她「あのね、巫女。あなた、誰かを待ったことある？」——她答不上来。她这辈子只做过「结束」的那一方。
- **镜子（四面/五面）**：文的「不写」是另一端的极端——一个拒绝结束的人；幽幽子的「不送」也是。灵梦发现全世界都在用别的方式拖着一件没做完的事，只有她，永远在关门。
- **落点（结局）**：**她第一次没有送。** 真结局里，她把死者的话「说」给活人听，而不是「念」给彼岸听。仪式没有进行，那句话留在了这边。

### 5.2 魔理沙 · 「借」与「还」

- **设定（可见）**：什么都借、什么都收。屋里的收藏全是「借」来的——从没人当真要她还。
- **裂缝（一段/开场）**：她口袋里那枚旧御守，她从十岁起就带着，一直以为是自己捡的最好的东西。她从来没打开过。
- **镜子（四面）**：文拍的那张照片里，先代的手是**空的**。魔理沙盯着照片看了很久：那只手本来要带东西去的。
- **落点（结局）**：**她第一次还了东西。** 真结局里，她把御守交出去——交出去的不是宝贝，是别人十年的约。

> 两个人的伤口互为镜像：灵梦**留不住话**，魔理沙**留住了不该留的东西**。一个该说没说，一个该还没还。

## 6. 逐面大纲

> 每面固定五槽：intro / mid[0]（道中 26%）/ mid[1]（道中 55%）/ preBoss / postBoss。  
> 每面都写清四件事：**夜在这里是什么样子** / **谁在按着「结束」** / **她的私心** / **打赢之后她失去了什么**。  
> 「玩家造成的遗憾」一栏，是这一面必须让玩家自己动手的地方。
>
> ⚠️ 这里是**骨架 + 关键台词**，不是逐字全文。第一夜（§8）已按成稿密度写满，作为样章与语感基准；方向确认后，其余五面按同一密度补成全文，句式与句数对齐旧版（intro 8–14 句 / mid 各 10–15 句 / preBoss 12–18 句 / postBoss 12–18 句，单句 20–40 字）。

### 第一夜 · 博丽神社（黄昏樱花）——「灯还没点」

- **夜的样子**：黄昏从早上挂到现在，影子钉在石阶上。石阶两侧挂满灯笼，一盏没点。屋台盖着布，布上落了两个月的樱。
- **谁在按着**：露米娅。她把每天该来的黎明**吃掉了**——她饿，黎明是甜的，吃了会困。她吃了七十次，所以天亮了七十次也没亮成。
- **她的私心**：她想睡觉。她已经七十天没睡了。她并不想留住夜，她只是想吃一口能让自己睡着的东西。
- **道中**：灵梦摇了第七十次铃。人里的老婆婆说这是「逢魔时」停住了——天要黑、或者天要亮的那一半。石阶上妖精在抢供品，抢到了也不吃，因为祭典没开始，吃了不算数。
- **preBoss**：露米娅拦路，说她闻得到门那边「線香の匂い」，那个人「まずいから」没吃。打赢她，她才会说下去。
- **postBoss（放锁）**：露米娅揉着眼睛说：「門のところに、ずっと立ってる人がいるの。……食べたら、いなくなるでしょ。いなくなるのは、やだ。」——她放走黎明，不是因为输了，是因为她突然不想再吃掉「会消失的东西」。
- **她失去了**：七十天来唯一能让她睡着的东西。之后她会继续失眠。
- **关键台词**：
  - 「明るいのは、まずいんだよ。でも、食べると、ねむくなるの」（露米娅）
  - 「あなた、誰かを待ったことある？」（露米娅问灵梦，灵梦没答）
  - 「異変は、終わらせればいい。……終わらせ方なら、知ってる」（灵梦）
- **魔理沙线差异**：她先想「借」走那些灯笼（好东西），被灵梦制止；她对露米娅说的第一句是「お前、その闇、売ってくれよ」——用买卖掩饰她其实想留下那点黑。
- **玩家造成的遗憾**：玩家赢了她，黎明回来了——但那孩子之后每一个夜晚都睡不着。

### 第二夜 · 魔法森林（萤火夜雾）——「萤火不睡」

- **夜的样子**：雾不散，萤火虫停在半空，像撒了一把不会掉的针。屋台的光透不进来。
- **谁在按着**：莉格露。她让萤火虫不睡，也让雾不散——**因为萤火虫只活一晚**。夜不结束，这一晚就不结束。
- **她的私心**：她想让「今晚」长一点。她不是在救谁，她只是舍不得。
- **道中**：萤火虫全部朝一个方向飞——朝着湖。魔理沙说这些虫子「急什么呢，祭典又不开」。
- **midtalk 的钉子**：莉格露说十年前有个巫女从这里走过，提着一盏**没点的灯**。「灯を、持ってたのに、点けてなかったんだぜ。変だろ」
- **preBoss**：莉格露挑战，说「お前が夜を終わらせたら、蛍は、明日には死ぬんだぜ」。
- **postBoss（放锁）**：她放萤火虫走。「蛍は、来年も来る。……あの人は、来年も来ないけどな。」她把那盏没点的灯指给灵梦——「あの人は、紅魔館の方へ歩いてった」。
- **她失去了**：这一晚的萤火。她的夏天提前结束了。
- **魔理沙线差异**：她认得那盏灯的形状（神社的式样），心里咯噔一下；但她说「知らない」——她开始撒谎了。
- **玩家造成的遗憾**：玩家赢了，夜继续走，萤火虫在黎明的第一线光里一起死掉。

### 第三夜 · 雾之湖（冰蓝晨曦）——「东边的天被冻住了」

- **夜的样子**：湖面结冰，冰下是黑的。东边的天空有一条很长的白痕，像被冻住的裂缝——那是黎明被拦下来的地方。
- **谁在按着**：琪露诺。她**受人之托**，用最硬的冰把东边的天冻住，「不让太阳起床」。
- **她的私心**：她终于被当成「最强」拜托了一次。她怕活儿干完了，就没人再拜托她。
- **道中**：湖上的冰面刻着一行歪歪扭扭的字：「あと、もう一晩だけ」。玩家看得出那是谁写的。
- **preBoss**：琪露诺骄傲地宣布自己的「工作」，说拜托她的人「線香の匂いがした」。
- **postBoss（放锁）**：她被问「誰に頼まれた」，答「巫女さん」。再问「いつまで続けるの」，她愣住——**没人告诉过她什么时候可以停**。她哭了一下，然后说「……もう、いいのか」，把冰化开。
- **她失去了**：第一份「被郑重拜托」的工作。
- **关键台词**：
  - 「わたし、いい仕事してるよね？」（琪露诺）
  - 「あと、もう一晩だけ」——冰面上的字
  - 「永遠は、妖精にも無いのよ」（灵梦引用映姬的话，只说一半，琪露诺没听懂）
- **魔理沙线差异**：她替琪露诺把冰面上的字拓下来（用纸和炭），说是「证据」。其实是想留着那行字。
- **玩家造成的遗憾**：玩家赢了，琪露诺失去了那份工作，也失去了「最强」的唯一证据。

### 第四夜 · 妖怪之山（瀑布溪谷）——「明天的报纸印不出来」

- **夜的样子**：溪谷的水声不变，因为夜一直没走完。山道上落满传单——**每一张都是同一个头版**：「例大祭、明日開催」。
- **谁在按着**：射命丸文。她七十夜都在红魔馆门口拍照，却一篇也没写。
- **她的私心**：她怕写完了，这个故事就结束了。记者是靠「还有下文」活着的人。
- **道中**：传单像雪。灵梦捡起一张，日期是十年前的。
- **preBoss**：文拦路，说「あなたを記事にしたいの」——她要的不是胜负，是题材。
- **postBoss（放锁）**：她给灵梦看一张照片：十年前，红魔馆门口，一个穿神社衣服的女人倒在雨里，手是空的。她说：「書けなかったのよ。……書いたら、終わっちゃうでしょう。」然后她说了「十回忌」三个字——灵梦这才知道今晚是什么日子。
- **她失去了**：十年的独家。以及一个可以一直不写的理由。
- **关键台词**：
  - 「真実は、水のようなものよ。……でも、水は、飲まなきゃならないの」（文）
  - 「この写真、あげるわ。私じゃ、渡せないから」（文把照片给灵梦）
  - 「先代の、十回忌よ」（文）
  - 「あくる朝、誰かが担いで帰ったわ。……年を越さずに、死んだ。あの人は、最後まで、扉を叩かなかった」（文——说明她不是死在门口：被抬回神社，那年冬天病死的）
  - 「この館の門はね、ノックした者にしか開かないのよ。……写真を撮っただけで、私は一度も叩いてない」（文，顺手把「门」这条规则埋给玩家）
- **魔理沙线差异**：她一眼看见照片里那只空手，脱口而出「手、空だぜ」；然后她的手伸进口袋，摸到了那枚御守，又缩了回来。
- **玩家造成的遗憾**：玩家赢了，文失去了「不写」的特权；她必须写完这个故事，而故事写完就是永别。

### 第五夜 · 白玉楼（冥界花海）——「死者没有回来」

- **夜的样子**：花海照旧开着，但一朵也不落。庭院的灯笼点着，是给「回来的人」照路的。
- **谁在按着**：妖梦放走了亡霊；幽幽子**拒绝**收回她。
- **妖梦的私心**：她看得见「没说完」。她的先代（妖忌）也是这样一声不吭走的，所以她放走了别人的先代。
- **幽幽子的私心**：她送走过太多人。这一次，她想看看「一个没说完的约」会怎么收场——她想当旁观者，而不是收尾的人。
- **道中**：庭院的石灯笼一盏盏亮着，像在等谁回来吃饭。
- **youmuPre / youmuPost**（关卡层级，不分线）：
  - 妖梦拦在桥头：「送るのは、私の仕事でした。……でも、送ったら、もう二度と、あの人の話を聞けない」
  - 打赢后：「……あなたに、任せます。私は、半分幽霊ですから。半分しか、送れないんです」
- **preBoss**：幽幽子端着茶，笑眯眯地说她不打算收回那个亡霊。「最後の詰めが肝心なのよ。……今回は、詰めないでおくわ」
- **postBoss（放锁）**：幽幽子说出了那句话——**死人的话，要有活人的嘴**。她还说：「あの人はね、『ごめん』が言いたいんじゃないの。『おいで』って言いたいのよ。」并且告诉灵梦：夜还被另一样东西按着——「永遠」。去月都。
- **她失去了**：一次旁观的机会。她终究还是把话说完了——她毕竟是收尾的人。
- **关键台词**：
  - 「送るのは、私の仕事でした。……でも、送ったら、もう二度と、あの人の話を聞けない」（妖梦）
  - 「死んだ人間の言葉は、生きてる人間の口を通らないと、届かないのよ」（幽幽子）
  - 「あなたは、送る人でしょう？ だったら、送る前に、聞いてあげなさい」（幽幽子对灵梦）
- **魔理沙线差异**：幽幽子一眼看见她口袋的形状：「あら、いいものを持ってるのね。……返す日が、来たんじゃない？」魔理沙装傻。
- **玩家造成的遗憾**：玩家赢了，妖梦必须承认自己「送不了」；幽幽子必须重新当回收尾的人。

### 第六夜 · 月都（永远亭）——「借出去的一夜」

- **夜的样子**：永远亭的竹林没有风。月亮的边缘有一道细缝，像一只没有闭上的眼。
- **谁在按着**：辉夜。十年前，她借给先代「再多一夜」——用那一夜走到门口；那一夜没有还回来，十年后叠成了七十天。
- **她的私心**：她嘲笑「半吊子的永远」，可她自己就是被永远流放的人。她给那一夜，是因为她想看看**一个知道自己要死的人，会拿这一夜做什么**。结果那个人拿去站在门口。
- **道中**：走廊上摆着五样东西（五つの難題的仿作），第六样是空的——那是先代留下的位置。
- **preBoss**：辉夜出题：「夜が明ける前に、私を負かしなさい」。
- **postBoss（放锁）**：她认输，收回永遠。她说：「半端な永遠ほど、たちが悪いものはないわ。……私が、それをあげたのよ。」然后她补一句：「あの人は、一度も扉を叩かなかった。……あなたは、叩くの？」
- **她失去了**：一个持续七十天的「半吊子永远」，也是她唯一一次心软。
- **关键台词**：
  - 「半端な永遠ほど、たちが悪いものはないわ」（辉夜）
  - 「あの人は、一度も扉を叩かなかった。……あなたは、叩くの？」（辉夜）
  - 「夜明けは、返すわ。もともと、私のものじゃないもの」（辉夜）
- **魔理沙线差异**：她盯着那第五样、第六样东西看了很久，说「ここ、空いてるぜ」——她认得出「空缺」这种东西。
- **玩家造成的遗憾**：玩家赢了，辉夜收回了她唯一一次心软；月亮重新开始走，那一夜永远地结束了。

### 第七夜 · 红魔馆（血月水晶）——「门」

（Extra 面。详见 §9）

- **夜的样子**：一年后的祭典前夜。红魔馆里第一次挂起了灯笼——祭典搬进了屋里，因为妹妹出不去。
- **谁在按着**：没有人。这一次没有异变，只有一场**请错了客人的宴会**。
- **客人**：请柬上写着「博麗先代様」。收信的人，去年已经走了。
- **蕾米莉亚的私心**：她替妹妹守了十年的谎，如今谎不用守了，她反而不知道自己是谁。
- **芙兰朵露的私心**：她其实一直知道客人不会来。她装作不知道，是怕姐姐哭。

## 9. EXTRA · 第七夜「第二夜的祭典」（红魔馆）

> 解锁条件不变：任一 TRUE ENDING 后解锁（`src/game/endings.js` 判定 / `hks.progress.v1.extraUnlocked`）。  
> 建议把标题页 EXTRA 按钮文案「禁忌的祭典」（`src/main.js:604-610`）改为「**第二夜の祭典**」——不再是禁忌，是一场迟到的宴会。

### 9.1 设定：这一次没有异变

真结局一年后。例大祭前夜。

红魔馆来信，信封上写「博麗先代様」。收信的人去年已经走了。

雷米莉亚在信里说：今年祭典在红魔馆里办——「あの子は外に出られないから」。整座馆挂满灯笼，中庭摆着屋台，地下室的门第一次打开了。

主桌旁有一张空椅子，名牌上写着「博麗先代様」。

**这一面没有元凶。** 玩家要对付的不是异变，是**一场请错了客人的宴会**，和两个不肯承认「客人不会来了」的人。

### 9.2 四段结构（EXTRA 的真实槽位）

> ⚠️ EXTRA 在引擎里只有四个槽：`extra.intro.{reimu|marisa}`、`extra.midBoss`、`extra.midBossOut`、`extra.postBoss.{reimu|marisa}`（`src/game/story.js:1058-1145`）。**没有** `preFinal` / `epilogue`——EXTRA 的结算直接接 `edW1` / `edW2` 本身，Boss 之前的最后一幕要并进 `midBossOut` 的末尾。

| 槽                 | 位置     | 内容                                                                                                                                     |
| ----------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| `intro`（分线）       | 进关     | 读完请柬，走到馆门前。门开着，灯亮着。灵梦/魔理沙各自对「先代様」这三个字的反应                                                                                               |

| `midBossOut`（不分线） | 雷米莉亚战后 | ①她说出十年里的谎：「来年、きっと来る」——她替妹妹说了十年；②她恨的不是先代失约，是先代**没有敲门就走**；③末段两人走下台阶，地下室的门口，芙兰朵露坐在台阶上，穿着祭典的和服，脚上没有穿鞋——她怕走出去（这一段是 `postBoss` 的开场铺垫，不再单列槽位） |

### 9.3 关键台词（EX 面）

- 雷米莉亚（midBoss）：「あの人が、来なかったんじゃない。叩かなかったのよ。……十年、待ったのは、こっちよ」
- 雷米莉亚（midBossOut）：「毎年、来年って言ってた。あの子に。……私が、言ってたの。あの人の代わりに」
- 芙兰朵露（`midBossOut` 末段）：「お客さま、来るかな。……わたし、ここで待ってる。お屋敷の外には、出ないから」
- 芙兰朵露（战后，W1）：「……そっか。来なかったんだ。……ううん、来たんだ。門のところまで」
- 芙兰朵露（战后，W2）：「魔理沙。その席、あの人の席だよ。……いいの？」／魔理沙：「借りてるだけだ。返す日は、来る」
- 咲夜（可选，门厅一句）：「お茶を、お持ちしました。……お客様の分も」

### 9.4 为什么不写「芙兰终于出门」

官方设定里芙兰从未离开红魔馆（`RESEARCH_CANON.md` 禁忌第 1 条），而且她真的踏出门，这个故事就变成了「大团圆」。

**本作的选择**：她一次也没有出门，但她**第一次走到了门厅**。祭典搬进了屋里，灯笼挂在她的走廊上。遗憾留在这里——她这辈子看见的最大一场祭典，是在自己家里办的。

## 11. 母题、意象与语感守则

### 11.1 五个母题（每个都只出现两三次，不解释）

| 母题     | 出现                 | 作用                      |
| ------ | ------------------ | ----------------------- |
| **门**  | 一面末／四面／六个结局        | 「叩」是全剧唯一的动作。敲门＝承认我来了    |
| **灯**  | 神社灯笼／没点的灯／W 结局的灯   | 点灯＝祭典开始；灯是「还亮着」的证据      |
| **御守** | 魔理沙开场／四面照片／ED3-ED4 | 信物。里面是十年前的信             |
| **铃**  | 七十次摇铃／神乐铃／每年第一声    | 灵梦的工具；「铃响了天没亮」是全剧的第一次失衡 |
| **空**  | 照片里空着的手／空椅子／空口袋    | 遗憾的形状                   |

### 11.2 语感守则（照旧版风格，写手必读）

1. 单句 ≤ 42 字；一段 6–18 句。
2. **每段最后一句是钉子**：一句短的、能独立成立的旁白或独白。
3. 旁白不解释情绪，只写动作和物件。让玩家自己推。
4. 括号独白每段最多一次，且只能是最疼的那一下。
5. 感叹号尽量少；用句号压住。
6. 角色口癖（官方锚点）：露米娅「そーなのかー」；琪露诺「なの」「最強」；莉格露「だってば」「〜ぜ」；文 敬体＋一句结构性的冷酷；妖梦「です！」；幽幽子「〜かしら」「のよ」；辉夜 高傲的断定句；雷米莉亚「〜わよ」「〜のよ」；魔理沙「〜だぜ」。灵梦少用语气词，多用短句断人。
7. 不写「爱」「永远」「命运」这类大词。用具体的：一枚御守、一盏没点的灯、一张空椅子。
8. 官方禁忌（`RESEARCH_CANON.md` D 节）：芙兰不出馆、蕾米惧日光、辉夜非 NEET、妖精非永恒、元凶不受罚。**六个 Boss 打赢后没有一个人被惩罚，最多说一句「そっか」。**

### 11.3 遗憾的配比（照 `RESEARCH_DOUJIN.md` C 节）

- 一面至四面：7 分轻松 3 分疼。Boss 都好说话，玩笑照打。
- 五面、六面：5 比 5。开始有人不肯送、不肯还。
- 结局：灵梦/魔理沙各一刀。
- EX：纯余韵，不再加新伤口，只让旧伤口每年疼一次。

## 13. 两个备选方案（如果 §0 那一句你不喜欢）

### B.《かくれんぼ》——「捉迷藏」

异变：幻想乡的孩子一个个消失，只剩声音。真相：十年前死掉的那个孩子在找玩伴，她一直在玩捉迷藏，**没人告诉她游戏已经结束了**。灵梦必须当那个「鬼」，找到她、喊出「もう終わり」。

落点：遗憾在「喊停的人」。灵梦擅长结束——这次她结束的是一场游戏，也是一个人最后的童年。  
风险：和官方「幻想乡的孩子」设定冲突较多，且芙兰/红魔馆线用不上。

### C.《忘れられた祭典》——「被忘掉的祭典」

异变：所有人都不记得去年办过祭典，但身上还挂着去年的面具。真相：先代死的那年，祭典为了服丧停办了一次；紫把那一年的记忆收起来了。

落点：遗憾在「没人记得」。灵梦要决定：把记忆还回去（大家会疼），还是不还（大家继续过日子）。  
风险：需要大量改动 NPC 与场景，成本最高；但「遗忘」是官方母题（茨歌仙最终话），文学性最强。

> 我的建议：**主线用《未明之约》**（成本最低、和现有六面/立绘/结局结构完全贴合），把《忘れられた祭典》的「被收藏的十年的记忆」作为 ED3/ED4 的一条暗线保留。
