# 移动端与多端操作手册

> 面向玩家和后续维护者。桌面端鼠标键盘操作、手感、画面**完全不变**；这里所有内容只在触屏 / 手柄 / PWA 环境生效。
>
> 相关：[`README.md`](../README.md) 的「移动端与多端」、[`docs/PLATFORMS.md`](PLATFORMS.md)（平台层）、[`docs/GAMEPAD.md`](GAMEPAD.md)（蓝牙手柄）、[`docs/MOBILE_QA.md`](MOBILE_QA.md)（自动化验收）。

## 1. 三种触屏方案怎么选

第一次用手机打开会自动出现虚拟手柄，默认**摇杆**。切换位置：

- 设置 → 操作 →「触屏方案」（键盘 `T` / 左右方向键也能切）
- 对局中点头柄右上角**齿轮** →「操作方案」，改完立即生效，不用退出

| 方案 | 适合谁 | 移动 | 动作键 |
| --- | --- | --- | --- |
| **摇杆**（默认） | 大多数玩家，手感最接近手柄 | 左下虚拟摇杆，半推慢走、推满奔跑 | 右侧射击 / 跳跃 / 低速 / 冲刺 / 符卡 |
| **手势** | 想要全屏、不喜欢按钮挡画面 | 左半屏按住拖动 | 右半屏按住射击、上滑跳跃、下滑低速、双指轻点符卡；左半屏双击冲刺 |
| **按键** | 不习惯摇杆、想要确定感 | 左下左右方向键 | 右侧动作键，排布和摇杆方案一致 |

三种方案共用同一套动作系统（射击、跳跃、低速、冲刺、符卡、暂停），和键盘 / 蓝牙手柄可以同时使用，互不抢输入。

### 摇杆方案的细节

- **模拟量**：摇杆不是把方向合成成「左/右」两个数字键，而是把 `x/y` 模拟量交给输入层；轻推真的会慢走，推满才是全速。输入层还有 0.12 的径向死区，摇杆面板里的「摇杆死区」默认 0.18，两者叠加后有效死区约 0.28。
- **8 方向吸附**：默认开启。方向会吸到上下左右 / 四个斜角，但**保留推杆幅度**——吸附只改方向，不把速度变成满速。想要完全自由的模拟方向，在齿轮面板里关掉「8 方向吸附」。
- **拖动起摇**：手指不用按在固定位置，落在摇杆区域附近就会以落点为中心起摇；松手自动回中。
- **低速（Focus）**：按住「低速」移速下降并显示判定点，和键盘 `Shift` 完全一致。

### 手势方案的细节

- 左半屏按住拖动 = 移动；双击 = 冲刺。
- 右半屏按住 = 射击；按住后上滑 = 跳跃；按住后下滑 = 低速。
- 右半屏双指轻点 = 放符卡。
- 手势区没有可见按钮；第一次进入会显示一次手势提示，之后可在齿轮面板里重新打开「手势提示」。

### 按键方案的细节

- 左下是两个方向键（左 / 右），按住即移动；右侧动作键和摇杆方案相同。
- 适合横屏时手指需要确定落点、或摇杆容易误触的玩家。

## 2. 齿轮面板与自定义布局

对局中点手柄右上角齿轮（暂停键左边），可以调：

| 设置 | 范围 / 说明 |
| --- | --- |
| 操作方案 | 摇杆 / 手势 / 按键 |
| 按键大小 | 0.8×–1.4×，立即重排 |
| 不透明度 | 0.3–1.0 |
| 摇杆死区 | 0.04–0.40；只影响摇杆方案 |
| 8 方向吸附 | 开 / 关；开启后方向吸附、幅度保留 |
| 震动反馈 | 按下动作 / 受击时的 `navigator.vibrate`（iOS Safari 不支持，静默跳过） |
| 手势提示 | 手势方案首次进入时的提示开关 |
| 布局编辑 | 拖动每个控件到顺手的位置；「重置」恢复默认；「完成」保存 |
| 恢复默认 | 当前方案的所有设置与布局回到默认 |

设置存在本机 `localStorage['hks.touch.v1']`，手势提示另有 `hks.touch.hints.v1`。布局按方案分别保存，换设备不会同步。

**布局编辑**也可以从 设置 → 操作 →「自定义按键布局」进入；编辑时控件会盖在菜单之上，安卓返回键先关编辑器，不会顺手退出暂停菜单。

## 3. 蓝牙 / USB 手柄

支持标准映射的 Gamepad API 手柄（Xbox、DualSense、DualShock、Switch Pro 等）。完整配对步骤、各平台震动支持与映射表见 [`docs/GAMEPAD.md`](GAMEPAD.md)，这里只记玩家最常用的部分：

- 先配对，再在页面上**按一下手柄任意键**，浏览器才会把设备暴露给网页；设置页「蓝牙手柄」会显示「已连接：手柄名」。
- 左摇杆模拟量移动；A 跳跃 / 确认，X 或 RT 射击，LB 或 LT 低速，Y / RB 冲刺，B 符卡，Start 暂停 / 返回，十字键导航菜单。
- 菜单和设置页也能用手柄：方向按住会重复（首次 300ms，之后 120ms），确认 / 暂停是单次边沿。
- 设置 → 操作 →「手柄震动」控制受击 / 放符卡 / 通关震动；iOS Safari 没有震动马达，会自动跳过。
- 死区与映射存在 `localStorage['hks.gamepad.v1']`；没有图形化改键 UI。

## 4. 安装、全屏与各端差异

### PWA / 添加到桌面

- `manifest.webmanifest` + `sw.js`（缓存版本 `hks-v1.6.1`）支持离线启动与自动更新；首次加载后断网也能进标题。
- Android / 鸿蒙 Chrome：标题页会出现底部「安装」条；设置 → 操作 →「添加到桌面」也能手动触发。
- iOS Safari：标题页会弹一次「分享 → 添加到主屏幕」图示；关掉后不再打扰。
- **安装条和 A2HS 图示只在标题页出现**，进入菜单、设置、对局、对话、结局时自动收起，不会盖住按钮或摇杆。
- 可安装性取决于部署层的 `Content-Type`：真部署需要 `.webmanifest` 返回 `application/manifest+json`；本地静态服务返回 `application/octet-stream` 时 manifest 仍能 200 + 解析，但浏览器可能不给安装入口。

### 全屏

- 设置 → 操作 →「全屏」调用 Fullscreen API；安卓 Chrome / 鸿蒙可用。
- iOS Safari 不支持网页全屏，从主屏幕图标启动时本身就是无地址栏的全屏。
- 微信 / QQ 内置 WebView 的全屏能力取决于宿主，拿不到时会显示提示，不会卡死。

### 安全区 / 旋转 / 后台

- 适配刘海、圆角、手势条：手柄控件与 HUD 都吃 `env(safe-area-inset-*)`。
- 竖屏可以玩，但 16:9 画面会上下留黑边，顶部有「↻ 建议横屏游玩 · 视野更完整」提示；建议横屏。
- 对局中切到后台会自动暂停；安卓返回键 / 手势返回按「关手柄面板 → 取消改键 → 推进对话 → 暂停 → 返回」逐级处理。
- 微信 / QQ 里音频要等第一次点按才解锁；平台层已把首次手势接到 `audio.unlock()`。

### 缓存排查

调试、验收、截图时给 URL 加 `?nosw=1` 跳过 Service Worker 注册，避免吃到旧缓存；正常玩家不需要。更新版本时同步改 `sw.js` 的缓存名与 `index.html` 里的 `?v=`。

## 5. 已知限制

- iOS Safari 没有 `navigator.vibrate`，触屏震动与手柄震动都不可用（不报错）。
- 网页全屏在 iOS 不可用；用「添加到主屏幕」替代。
- 竖屏是 16:9 letterbox，不是重新排版关卡；这是刻意的，横屏体验最好。
- 内嵌 WebView 可能禁用 Gamepad API、Fullscreen API 或 Service Worker；平台层会降级，不会阻塞游戏。
- 非标准布局手柄按标准 index 读取，按键可能错位；状态会标「非标准布局」。

## 6. 自动化验收

手机 / 平板 / 折叠屏 / 微信 UA 的多端回归脚本：

```bash
# 全部设备 × 横竖屏 + PWA + 手柄 mock（约几分钟）
node tools/_mobile_qa.mjs

# 只跑 iPhone 13 横屏
node tools/_mobile_qa.mjs --device=iphone13 --orientation=landscape

# 微信 UA
node tools/_mobile_qa.mjs --device=wechat
```

产物：`_shots_mobile/report.md`（人读）、`_shots_mobile/report.json`（机器读）、`_shots_mobile/<device>/<orientation>/*.png`。报告会检查：画布居中、虚拟按键是否越界 / 互相重叠 / 挡 HUD、设置页底部按钮是否可见、安装条是否只在标题页、console error、失败资源、FPS、旋转复位、PWA manifest / SW / 离线。

平台层单独的探针：`node _pt/plat/desktop_diff.mjs`（桌面 1280×720 零差异）、`mobile_probe.mjs`、`offline_probe.mjs`、`gamestate_probe.mjs`、`settings_shot.mjs`。

## 7. 代码位置

| 文件 | 职责 |
| --- | --- |
| `src/ui/virtualPad.js` | 触屏手柄：三方案、布局编辑、齿轮面板、设置持久化、i18n |
| `src/ui/mobile.css` | 手柄视觉与安全区；`body.hks-pad-on` / `#hksTouchPad` 作用域 |
| `src/engine/input.js` | 键盘 / 触屏 / 手柄三来源并集；模拟量 `moveX/moveY`；分来源边沿 |
| `src/engine/gamepad.js` | Gamepad API 轮询、映射、死区、震动、菜单方向重复 |
| `src/ui/platform.js` + `platform.css` | 环境识别、PWA、全屏、安装条、返回键、安全区、`setGameState` |
| `src/main.js` | 状态机 → 手柄 / 平台语义状态；设置页「操作」组；系统返回键逐级处理 |
| `sw.js` / `manifest.webmanifest` | 离线缓存与安装元数据 |
