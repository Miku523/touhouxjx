# Boss 符卡限时与目标血量表（v4 · 2026-10-24 全 43 张重定标）

> 数据源：`docs/BOSS_TIMING_SPEC.md` §1（用户 2026-10-24 口述的逐卡新限时）。
> 代码数据：`src/game/bossTuning.js`（`BOSS_CARD_TUNING` / `cardTuningFor`）。
> 血量公式：击破卡 / 双条件卡 `hp = Math.max(1, Math.round(limit × dps × CARD_HP_ANCHOR))`，`CARD_HP_ANCHOR = 0.918`，**不乘难度血量系数**（跨难度时长一致）。
> 血量锚点：`0.4（火力 Lv2 主弹 2/5）× PLAYER_ATK_SCALE 2.7 × CARD_DPS_CAL 0.85 = 0.918`，含义是「**Lv2 火力、不落命** 的玩家约在 0.76×limit 打空」，Lv3 ≈0.51×、Lv4 ≈0.30×。
> 单卡难度档（1–5，`CARD_TIER_MUL`）只调这张卡的弹数与弹速：1 = ×0.75/×0.90，2 = ×0.88/×0.95，3 = ×1.00（基准），4 = ×1.15/×1.06，5 = ×1.30/×1.12。
> survival 卡 Boss 免疫伤害、`dps = null`、无血量；`both` 卡撑满限时或打空血条都算过关。

> 范围：全部 **43 张**（主线 28 + 5 面中途妖梦 3 + EXTRA 12）。限时合计 **2526s**，运行期血量合计 **279,961**。
> 模式分布：击破 37 / 存活 5 / 双条件 1。存活卡：4-5、5-4、6-7、芙-4、芙-7；双条件卡：芙-10。

## 3. 与 v3 的差异

- 限时：全部按用户 2026-10-24 口述整体压缩（主线 3189s → 1736s（28 张关底卡；含妖梦为 1841s），EXTRA 12 张首次接入限时与结算奖励）。
- 血量：锚点从「满火力 Lv4 打 0.76×limit」下调到「**Lv2 打 0.76×limit**」，系数由 `limit × dps` 变为 `limit × dps × 0.918`。
- 模式：4-2 / 6-1 / 6-8 由存活卡改为击破卡；6-7 由击破卡改为存活卡；芙-10 新增「双条件」模式。
- 难度：新增逐卡 1–5 档，替代原先只有存活卡才有的 `densityMul` / `speedMul` 散装倍率。

## 4. 实测验证（2026-10-24，改完后跑）

工具：`tools/_verify_bosscards.mjs`（主线验收）、`tools/_ex_card_dps.mjs`（EXTRA 逐卡），
都是 CDP 无头 Edge + `tools/sim_bot.js`（god 无敌 / 灵梦），逐帧读 Boss 自己的 `lastCardResult.elapsed`。
「占比」= 耗时 ÷ 限时；设计目标 **Lv2 ≈ 0.76×**、Lv3 ≈ 0.51×、Lv4 ≈ 0.30×。

### 4.1 主线抽样：1 面 露米娅（Normal）

| 卡 | 限时 | 运行期血量 | power 32（Lv2） | power 64（Lv4） |
|---|---|---|---|---|
| 宵暗「月之暗面」 | 50 | 8,078 | 39.6s / **79.2%** | 16.6s / **33.2%** |
| 暗符「黑暗吞噬」 | 60 | 9,804 | 19.9s / 33.2%（后段被 P 点顶到 Lv3–4） | 17.8s / **29.6%** |

power 48 / 64 两档实测都会在一两张卡内被道中 P 点顶满 Lv4（上限就是 5 发主弹），
所以「Lv2」只有起手 `carryPower = 32` 才测得出来。

结论：
- 9 张击破卡 + 芙-10 满火力落在限时的 **22–33%**（设计 30%），与主线一致；
  二档按 0.4 弹量比反推约 **75%**，即「二档不落命刚好打掉」，掉一条命就超时；
- 两张存活卡都在设定秒数**整点 break**（30.02 / 120.02s），血量不参与判定；
- 芙-10 走「打空血条」分支在 34s 左右正常结束（57%），撑满 60s 的另一条分支同样成立；
  它的血量 6,778 仍是全 EXTRA 最高（第二是芙-6 的 6,293）；
- 单卡 dps 的 run-to-run 抖动很大（同一张卡不同 seed 可差 2 倍，bot 走位/命中率所致），
  所以占比是按 20-seed 均值反推、再用 3 seeds 抽查，不追求单次落点精确。
