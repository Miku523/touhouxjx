## 3. 血量口径与待确认

1. **血量公式（2026-10-20 起）**：限时卡（stage1–6 共 28 张）运行期血量 = `Math.max(1, Math.round(limit × dps))`，**不乘难度系数**（不再乘 hpScale）。`基准血量` 列与 `hpMul` 仅保留作 `BOSS_DEFS` 历史对照，不参与限时卡血量计算。
2. **目标有效血量** = `limit × dps`，只对 damage 卡成立；survival 卡 Boss 免疫伤害，`dps = null`、不填 `hp`。
3. **dps 来源**：2026-10-20 验收工具实测（Normal，满火力 `--power 64`、`--seed 12345`）×0.76 成功裕度（= 旧 ×0.95 值再 ×0.8）；`dps_new = round(dps_old × 0.8)`。**限时卡血量不乘难度系数**。
   - 2026-10-21 变更（用户 m00001 / m00123）：仅 stage1–6 的 **23 张 damage 卡** dps ×0.8，`limit` 与 5 张 survival 卡不变，**EXTRA（remilia / flandre）除外、未调整**。
   - 验收口径同步改为 `ratio = elapsed/limit`：`ratio ≤ 0.95` 为 PASS（余量 ≥5%）；`< 0.65` 仅告警（打得偏快，多为 bot 噪声）；全难度 0 失败（见 `BOSS_TIMING_VERIFY.md`）。
4. **待确认**：辉夜第 6 卡 240s 是用户未指定时的暂定值（spec §5），验收后需向用户确认。
5. **取中值说明**：莉格露 #2（90–120→105）、莉格露 #3（60–120→90）、琪露诺 #3（60–120→90）、幽幽子 #3（120–180→150）均为用户给区间后取中值，非用户精确指定。
6. **名称偏差**：辉夜 #7 spec 表写「难题「燕之子安贝 -不死之药-」」，`BOSS_DEFS` 现名为「难题「燕的子安贝 -永命线-」」（两处不同：子安贝 / 之子安贝；不死之药 / 永命线）。本表与 `bossTuning.js` 暂以 `BOSS_DEFS` 为准，待 Lead 决定是否改名后同步。
7. **fx / effect 已定稿回填**：已按 `docs/BOSS_CREATIVE_DESIGN.md` §一 回填（2026-10-20），合法键见 `cardfx.js` 的 `FX_KEYS` 与 `cardEffects.js` 的 `EFFECT_KEYS`；本表不再维护占位说明。
8. **卡数口径**：spec / 任务写“30 张”，但 spec §1 表格只有 28 行、各面卡数 2/3/4/5/6/8 相加 = 28，`BOSS_DEFS` 也是 28 张。本表与 `bossTuning.js` 均按 **28 张**落地；“30” 判定为笔误，如确需补 2 张请先补 spec 表与 `BOSS_DEFS`（当前无卡可补）。
9. **文面 dps 偏低**：射命丸文的 damage 卡 dps 125–142（旧值 156–171），明显低于其他面（147–178），是 stg 关 bot 站位命中率低造成的关型差异，属预期，未人为拉平。
