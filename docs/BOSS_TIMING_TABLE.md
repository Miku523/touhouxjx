# Boss 符卡限时与目标血量表（v6 · 2026-10-25 下午整体再下调）

> 数据源：`docs/BOSS_TIMING_SPEC.md` §1（用户 2026-10-24 口述的逐卡新限时）。
> 代码数据：`src/game/bossTuning.js`（`BOSS_CARD_TUNING` / `cardTuningFor`）。
> 血量公式：stage1–6 击破卡 `hp = Math.max(1, Math.round(limit × dps × CARD_HP_ANCHOR))`，`CARD_HP_ANCHOR = CARD_LV3_SHARE = 0.655`，**不乘难度血量系数**（跨难度时长一致）。5 面中途妖梦 3 张单独写死 `hp`（= `limit × dps × 0.655 × 0.90`，比主线再松 10%）。EXTRA 11 张击破卡一律用显式 `hp` 钉死（2026-10-25 按「三挡 0.77×limit」标定，见 §4.2）。
> 血量锚点：`0.655` 是**三挡火力（Lv3，power 48）**下自动 bot 打空所需的时间占比；bot 开无敌敢贴脸，真人同卡约慢 1.2–1.35×（占比 0.79–0.88），也就是 60 秒卡打完还剩 7–13 秒（典型 9–10 秒）。EXTRA 取 `CARD_EX_SHARE = 0.77`（= 0.655 × 1.18，比主线再硬 15–20%）。
> 单卡难度档（1–5，`CARD_TIER_MUL`）只调这张卡的弹数与弹速：1 = ×0.75/×0.90，2 = ×0.88/×0.95，3 = ×1.00（基准），4 = ×1.15/×1.06，5 = ×1.30/×1.12。
> survival 卡 Boss 免疫伤害、`dps = null`、无血量；`both` 卡撑满限时或打空血条都算过关。

> 范围：全部 **43 张**（主线 28 + 5 面中途妖梦 3 + EXTRA 12）。限时合计 **2556s**，运行期血量合计 **360,475**（v4 334,651 → v5 398,694 → 本版 −9.6%）。
> 模式分布：击破 38 / 存活 4 / 双条件 1。存活卡：4-5、5-4、6-7、芙-4；双条件卡：芙-10。

## 3. 与 v5 的差异（2026-10-25 下午「整体再下调」）

- **锚点 0.72 → 0.655**（`CARD_LV3_SHARE`）：用户 2026-10-25 下午反馈上一版打起来偏紧，要求「都下调一些血量，中下程度」。60 秒卡真人余量从 5–6 秒拉到 7–13 秒（典型 9–10 秒）。
- **妖梦 3 张再降 10%**：5 面中途妖梦改成显式 `hp = round(limit × dps × 0.655 × 0.90)`（6,111 / 5,104 / 8,009 → 5,003 / 4,179 / 6,558），符合用户「魂魄妖梦适当下调」。
- **EXTRA 11 张 ×0.906**：`CARD_EX_SHARE` 0.85 → 0.77（= 0.655 × 1.18），维持「EX 比主线硬 15–20%」的相对强度。
- **限时 / 模式 / 档位 / dps 全部不变**：仍是 43 张、限时合计 2556s；存活卡仍是 4-5、5-4、6-7、芙-4；双条件卡仍是芙-10。
- **总血量 398,694 → 360,475（−9.6%）**：各面等比下调，分面降幅一致（aya 面仍是最重的 42k 档）。

## 4. 实测验证（2026-10-25 下午版，三挡口径）

工具：`tools/_verify_bosscards.mjs`（主线 1–6 面整关跑）、`tools/_ex_card_dps.mjs`（EXTRA 逐卡），都是 CDP 无头 Edge + `tools/sim_bot.js`（灵梦、`--god` 无敌、不放炸弹）。
**`--lockPower 48` 每帧把 POWER 钉死在三挡（Lv3 = 3 发主弹）**，吃 P 点也不会升档污染数据。「占比」= `elapsed / limit`。

验收门槛：bot 占比目标 **0.655（主线）/ 妖梦 0.59 / EXTRA 0.77**；bot 开无敌敢贴脸，同卡比真人快 1.2–1.35×，折算到真人就是 **0.79–0.88×limit** —— 60 秒卡打完还剩 7–13 秒（典型 9–10 秒）。
