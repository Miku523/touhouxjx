# Boss 符卡限时与目标血量表（v5 · 2026-10-25 三挡重定标）

> 数据源：`docs/BOSS_TIMING_SPEC.md` §1（用户 2026-10-24 口述的逐卡新限时）。
> 代码数据：`src/game/bossTuning.js`（`BOSS_CARD_TUNING` / `cardTuningFor`）。
> 血量公式：stage1–6 击破卡 `hp = Math.max(1, Math.round(limit × dps × CARD_HP_ANCHOR))`，`CARD_HP_ANCHOR = CARD_LV3_SHARE = 0.72`，**不乘难度血量系数**（跨难度时长一致）。EXTRA 11 张击破卡一律用显式 `hp` 钉死（2026-10-25 按「三挡 0.85×limit」标定，见 §4.2）。
> 血量锚点：`0.72` 是**三挡火力（Lv3，power 48）**下自动 bot 打空所需的时间占比；bot 开无敌敢贴脸，真人同卡约慢 1.2–1.35×（占比 0.87–0.97），也就是 60 秒卡打完还剩 5–6 秒。EXTRA 取 `CARD_EX_SHARE = 0.85`（= 0.72 × 1.18，比主线再硬 15–20%）。
> 单卡难度档（1–5，`CARD_TIER_MUL`）只调这张卡的弹数与弹速：1 = ×0.75/×0.90，2 = ×0.88/×0.95，3 = ×1.00（基准），4 = ×1.15/×1.06，5 = ×1.30/×1.12。
> survival 卡 Boss 免疫伤害、`dps = null`、无血量；`both` 卡撑满限时或打空血条都算过关。

> 范围：全部 **43 张**（主线 28 + 5 面中途妖梦 3 + EXTRA 12）。限时合计 **2556s**，运行期血量合计 **398,694**（v4 为 334,651，+19.1%）。
> 模式分布：击破 38 / 存活 4 / 双条件 1。存活卡：4-5、5-4、6-7、芙-4；双条件卡：芙-10。

## 3. 与 v4 的差异（2026-10-25 三挡重定标）

- **血量锚点换了**：v4 是「Lv2 火力 0.884 / EXTRA 满火力 0.304」，v5 改成「**三挡 Lv3 = 0.72**」（`CARD_LV3_SHARE`）+「EXTRA `CARD_EX_SHARE = 0.85`（= 0.72 × 1.18）」，也就是用户 2026-10-25 的「EX 再硬一点点，1.15–1.2 倍」。
- **逐卡 `dps` 全部重测回填**：主线 39 张用 `--lockPower 48` 钉死三挡、3 seeds 取中位；EXTRA 11 张用 8 seeds 多轮取中位再反推显式 `hp`。旧 dps 是 2026-10-21 攻击力翻倍前的旧单位，作废。
- **限时 / 模式 / 档位不变**：仍是 v4 的 43 张（限时合计 2556s）；存活卡仍是 4-5、5-4、6-7、芙-4，双条件卡仍是芙-10。
- **总血量 334,651 → 398,694（+19.1%）**：多数面 +10~20%，aya 面因为 bot 站位好（三挡实测 330–370 dps）而翻了 2 倍上下，是这次涨幅最大的面。

## 4. 实测验证（2026-10-25，三挡口径）

工具：`tools/_verify_bosscards.mjs`（主线 1–6 面整关跑）、`tools/_ex_card_dps.mjs`（EXTRA 逐卡），都是 CDP 无头 Edge + `tools/sim_bot.js`（灵梦、`--god` 无敌、不放炸弹）。
**`--lockPower 48` 每帧把 POWER 钉死在三挡（Lv3 = 3 发主弹）**，吃 P 点也不会升档污染数据。「占比」= `elapsed / limit`。

验收门槛：bot 占比目标 **0.72（主线）/ 0.85（EXTRA）**；bot 开无敌敢贴脸，同卡比真人快 1.2–1.35×，折算到真人就是 **0.87–0.97×limit** —— 60 秒卡打完还剩 5–6 秒。
